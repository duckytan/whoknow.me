## 1. 屏幕流（Screen Flow）

### 1.1 全链路（ASCII 概览）

```
[商品列表 BROWSE_LIST]                        仿淘宝: 金刚区 + 商品卡 + 底部 TabBar (--mart-host 宿主伪装)
        │ 玩家点商品卡
        ▼
[商品详情 BROWSE_DETAIL]                      图 + 名 + 价占位(禁真实数字) + 销量灰字 + 结算 CTA
        │ 玩家点「结算」(--mart-host 填充)
        ▼
[导购闪现 INTRO / 首爆点 P6]                  ≤3s 导购毒舌劝退闪现 (弹簧入场, 触发博弈)
        │
        ▼
[选项呈现 ROUND]                              4 选项位置随机(shuffle) 出现 (06 戏精弹层)
        │ 玩家点选 1 招 (核心输入)
        ▼
[克制反馈 EVALUATE]                           查 matrix → affinity += moodDelta
        │   +40 命中弱点: 绿光晕 + 单次抖动≤300ms + 浮动「+40」(--brand-green)
        │   -10 踩雷:   选项微缩 + 警示描边 + 浮动「-10」(中性灰, 非红)
        │   +10 平手:   中性微反馈 + 浮动「+10」
        │
        ├─ affinity >= 100 ─────────▶ [结算·破防态 WIN_BREAK]    绿框「服了，下单吧」(success)
        ├─ affinity <= 0   ─────────▶ [结算·反消费胜利态 WIN_ANTI] 绿框「省钱了，下次别来」(success)
        └─ 0 < affinity < 100 ──────▶ [归零态 / 中局中性态]  「平局/未破防」中性提示 (无红叉)
                                        │  round++ → 回 ROUND (位置重随机)
                                        └─ round >= roundCap → 强制 WIN_ANTI 劝退 (防死循环, 仍 success)
```

> **归零态术语对齐（重要）**：`00-CONCEPT.md` §4.3 与 `REVIEW.md` §2 将「归零态」概念等同于「反消费胜利态 WIN_ANTI」。`08` 与 `03` 进一步规定**终端结局只有两种绿框胜利（WIN_BREAK / WIN_ANTI），绝不出现红叉**。本规格为落实 Phase 4 brief 的「归零态 = neutral 平局/未破防反馈」，将「归零态」细化为**中局中性态**（affinity 落在 (0,100) 且未达任一胜利阈值的实时状态），其反馈为中性「平局/未破防」提示、无红叉、无胜利印章，引导玩家继续博弈。终端结局仍严格为双胜利绿框，与已审 GDD 完全一致（G-4 不漂移）。

## 2. 玩家输入点（Player Input Points）

| # | 输入点 | 触发位置 | 交互 | 映射到状态机 | 设计意图（支柱/心理学） |
|---|--------|----------|------|--------------|------------------------|
| ① | 点商品卡 | BROWSE_LIST | 单点 | → BROWSE_DETAIL | 逛（P3 宿主习惯复用） |
| ② | 点「结算」CTA | BROWSE_DETAIL | 单点 | → CHECKOUT_TRIGGER → INTRO | 点（P6 首爆点 ≤3s） |
| ③ | **选 4 选项之一** | ROUND（戏精弹层） | 单点（核心输入） | → EVALUATE（查 matrix） | 怼/撬（P4 选择触发戏精 · 自主） |
| ④ | 结局后操作 | WIN_BREAK / WIN_ANTI | 单点「截走」/「换导购」 | → 08 出图 / → 回访 | 截（P2 截图即胜利）· 访（P5 回访） |

> **输入点③为重点**：4 选项每轮**位置随机 shuffle**（seed 来自 `MartRoundState.positionSeed`），4 招全出现、不重复、不可预测顺序——满足 P4「防肌肉记忆」（H5 选择分布均匀，无单招 >50%）。
> 位置随机由 L2 运行时控制，**不在 L1 存**（见 `02` §2 / `mart-L1-datastructure-draft.md` §2）。

## 3. 状态映射（MartRoundState → UX）

`MartRoundState`（定义见 `02-selection-statemachine.md` §2）各字段的 UX 呈现：

| `MartRoundState` 字段 | 类型/来源 | UX 呈现 | 说明 |
|---|---|---|---|
| `guideId` / `guideArchetype` | L1.mart.guides | 导购头像(emoji) + 角色色底(`--role-*`) + 名 | 见 `REVIEW.md` §5.1 |
| `affinity` (0~100) | L2 运行时 | 破防 meter：数值(`--font-mono`)+阶段文案+色带 | 不渲染为「财力/智商」标尺（ART-BIBLE §9.1 #4） |
| `round` / `roundCap` | L2 运行时 | 可选「第 N / 上限」微文案（默认隐藏，防焦虑） | `roundCap` 到达→强制 WIN_ANTI |
| `tags` | L2 跨轮 | 叙事标签（影响导购对白分支，可选呈现） | 弱叙事线（Narrative ★☆☆） |
| `selectedHistory` | L2 运行时 | 图鉴「招式见过」写回（05） | P5 收集 |
| `positionSeed` | L2 每轮 | 驱动 4 选项 shuffle | P4 防肌肉记忆 |
| `optionsThisRound` | L2 每轮 | 戏精弹层 4 选项组（图标+文字双标识） | 色盲友好（ART-BIBLE §2.5） |

**状态→屏幕映射总表**

| 状态机态 | 屏幕 | 关键 UX 动作 |
|---|---|---|
| `CHECKOUT_TRIGGER` | 详情页结算 | 宿主 CTA 触发 |
| `INTRO` | 导购闪现 | ≤3s 首爆点毒舌（P6 硬约束） |
| `ROUND` | 选项呈现 | 4 选项 shuffle 渲染 |
| `EVALUATE` | 克制反馈 | 查 matrix → 浮动 delta 反馈 |
| `WIN_BREAK` | 结算卡·破防态 | 绿框「服了，下单吧」 |
| `WIN_ANTI` | 结算卡·反消费胜利态 | 绿框「省钱了，下次别来」 |
| （中局）归零态 | 中性气泡 | 「平局/未破防」提示 → round++ |

## 4. 双胜利 + 归零态 反馈（Feedback）

### 4.1 三种结局反馈规范

| 态 | 触发条件 | 视觉 | 文案（来自 `03`/`08`） | 语义 |
|---|---|---|---|---|
| **WIN_BREAK 破防态** | `affinity >= 100` | 绿框 + `--brand-green` 高亮梗框 + 弹簧入场 | 「服了，下单吧」 | success（掌控爽） |
| **WIN_ANTI 反消费胜利态** | `affinity <= 0` 或 `round >= roundCap` | 绿框 + 绿高亮梗框 +「反套路赢」印章(`--font-brush`) | 「省钱了，下次别来」 | success（省了钱也是赢） |
| **归零态 / 中局中性态** | `0 < affinity < 100`（实时） | **无红叉、无胜利印章**，仅中性气泡 + meter 续显 | 「平局/未破防，再来一招？」 | **中性**（非输、非赢），引导续博弈 |

> **红线（G-4 / ART-BIBLE §2.4 / §5.4 / §9.1 #5）**：WIN_BREAK 与 WIN_ANTI **均为 success 语义**，归零态**绝不**渲染为「失败 / 红叉」等输家态。任何把归零态画成红叉的产出，视觉自检拒收。
> **`round_cap` 兜底**：玩家一直选踩雷招未到阈值时，`round >= roundCap` 强制解析为 WIN_ANTI（劝退），保证无死循环且仍 success（防心流崩坏，`00-CONCEPT.md` §5.2）。

### 4.2 克制反馈（EVALUATE 即时反馈）

| delta | 来源 | 反馈动作（≤300ms） | 颜色/字 |
|---|---|---|---|
| `+40` 命中弱点 | `matrix[archetype][move] == 弱点` | 头像/气泡 `--shadow-glow-green` 光晕 + 单次抖动 + 浮动「+40」 | `--brand-green` |
| `-10` 踩雷 | `matrix[archetype][move] == 踩雷` | 选项 `scale(.97)` + 警示描边(`--brand-orange` 或 `--role-*`) + 浮动「-10」 | **中性灰，非红**（不触发「输」感） |
| `+10` 平手 | 其余 2 格 | 中性微反馈 + 浮动「+10」 | 中性灰 |

> 踩雷反馈**禁用红色**（避免与「失败/红叉」语义混淆）；用锚色橙或角色色做警示描边，保持中性。

## 5. SDT / 心流 对齐（心理学意图落地）

本规格的每处交互须可回溯到 `00-CONCEPT.md` §5 的心理学框架。

### 5.1 自我决定论（SDT）

| 维度 | UX 落点 | 对应屏/机制 |
|---|---|---|
| **自主 Autonomy** | 4 选项自选 + 位置随机不预置「标准答案路径」；胜负由话术选择决定，非数值碾压 | 输入点③ / ROUND |
| **胜任 Competence** | 破防 meter 可见涨落 + 命中弱点 `+40` 即时正反馈 + 双胜利可达；保底轮次防「逼半天还不卖」 | EVALUATE / WIN_BREAK |
| **关联 Relatedness** | 导购动机 B（打工人整资本）/ C（真为玩家好）与玩家同阵营，戏精共谋 solidarity 非欺凌 | INTRO 对白 / lineBuckets（见 `PHASE4-CONTENT.md`） |

### 5.2 心流平衡（Challenge vs Skill）

- **挑战侧**：affinity 涨跌 + 隐藏弱点探索提供适度不确定性（H2 笑率 / H5 分布）。
- **技能侧**：玩家靠「试招→归纳弱点」提升胜率（非随机），满足 Competence。
- **防崩坏**：保底轮次（N 轮内必存在可达破防路径）+ `round_cap` 上限（防死循环）→ 单局 5–15min 可控（`00-CONCEPT.md` §5.2 / §10）。

### 5.3 Bartle 覆盖（参考）

| 类型 | UX 落点 |
|---|---|
| 成就者 | 图鉴（招式见过/弱点击中）+ 成就 `Rarity`（P5，08 出图） |
| 探索者 | 发现每导购隐藏弱点（matrix）+ 台词分支（`tags`） |
| 社交家 | 截图分享朋友圈（输入点④ → 08） |
| 杀手 | 以毒攻毒「赢」导购（move_poison 命中弱点 +40） |

## 6. 可访问性 & 禁忌词接线（Accessibility & Red-Line）

### 6.1 可访问性基线（对齐 `ART-BIBLE.md` / `BRAND.md` §17）

| 项 | 规范 | 落点 |
|---|---|---|
| 触控目标 | ≥ 44×44px | 4 选项 / CTA / 结算卡按钮 |
| 色盲友好 | 图标 + 文字双标识，状态不色独载 | 选项 emoji+label；meter 带数值+阶段文案 |
| 动效减弱 | `@media (prefers-reduced-motion: reduce)` 全瞬时 | 弹簧入场/抖动降级瞬时（BRAND §16/§17） |
| 焦点环 | `--brand-orange` 3px, offset 2px | 键盘可达（ART-BIBLE §7.1） |
| 对比度 | 正文 `--fg`#222 on `--bg-2`#fff ≥ 4.5:1 | 截图社交压缩后仍清晰（08 §2） |

### 6.2 水印分离（P2 截图即胜利）

`ui_meta` 水印**只进页脚**（首页 / 结算底部），**绝不**覆盖戏精弹层 / 气泡 / 结局卡（api-spec §P0-3 D3）。截图保持干净淘宝伪装。

### 6.3 禁忌词接线（forbidden_check · L1-T1）

所有屏文案（导购对白 / 招式 label / 结算卡 / 微文案 / 店名 / 价格占位）须过 `forbidden_check`：
- `red_light_count > 0` → **整包拒绝** → L4 降级诚实告知「今天没新段子」（07 §3）。
- 黄灯（竞品→某宝/某团；真人→某明星；地名→京城）须化名（07 §1）。
- 价格占位**禁真实数字**（红线 #2，01 §4）；店名/品牌全化名（09.2 化名规则）。

## 7. 验收（Acceptance）

- [ ] 进商品页 / 点结算 ≤3s 导购闪现首爆点（P6 硬约束）。
- [ ] 每轮 4 选项位置随机且 4 招全出现（连续 10 轮无单招 >50%，H5）。
- [ ] `affinity >= 100` → 破防态绿框「服了，下单吧」；`<= 0` → 反消费胜利态绿框「省钱了，下次别来」。
- [ ] `round_cap` 到达 → 强制 WIN_ANTI 劝退，无死循环。
- [ ] 归零态（中局中性）渲染为中性「平局/未破防」提示，**无红叉、无胜利印章**，引导续博弈。
- [ ] 踩雷反馈禁用红色，用 `--brand-orange`/角色色警示描边，中性灰浮动「-10」。
- [ ] 4 选项图标+文字双标识，焦点环 `--brand-orange` 3px，`prefers-reduced-motion` 降级瞬时。
- [ ] 截图/气泡/结局卡无水印（页脚除外，P2）。
- [ ] 任意屏出现红线词 → 整包拒绝，绝不渲染敏感内容（否决#3 机检通过）。
- [ ] 破防 meter 带数值+阶段文案，不渲染为「财力/智商」标尺。
