## 〇、v1 现状（诚实复盘）

| 维度 | v1 状态 |
|---|---|
| 概念 / 系统设计 | ✅ 三份灵魂文档 + 选招制状态机 + 破防度引擎 + 5导购×弱点矩阵 |
| 可看原型 | ✅ 九屏 v1 上线 `/mart`，桌面温和适配已加 |
| 可玩性 | ⬜ **不可玩**：纯静态展示，无运行时、无真分支、数值全占位 |
| 真机验证 | ⬜ 等真人 playtest（总纲唯一硬闸门） |
| 接 brain | ⬜ 等外卖 `DATA-STRUCTURE-v1` 字段落定（M1 解冻前提） |

**结论**：v1 是「能看的反骨 demo」，不是「能玩的游戏」。v2 的任务是把 demo 推进到「可玩验证版」。

---

## 一、v2 目标（一句话）

> 在保持纯前端、不依赖 brain 的前提下，**让 v1 原型变成「真人能真机玩出核心循环」的最小可玩版**，并产出接 brain 前的全部备料。

不追求美术/性能完美，只追求：**核心循环可玩、可测、可标定**。

---

## 二、工作分解（W1–W6，含依赖）

### W1 · 真实立绘（美术资产 · art-director 主导）
- 输出：5 导购概念立绘（贴合反骨人设：王二麻毒舌、李算盘算账、赵拖拖散漫、钱满满鸡汤、周暗暗腹黑）
- 下游：`art-director` 出《mart 美术圣经》→ 立绘规格 → 资产
- 依赖：无（可立即启动）
- 当前：v1 用 emoji 占位，v2 替换为概念图

### W2 · 多入口对话延续（本路线图已起步 ✅）
- 输出：localStorage 记录每导购访问次数；第 ≥5 次进店态度软化（"同店第5单差异"）
- 价值：直接服务 playtest 硬指标「同店第5单差异」
- 依赖：无（纯前端，已落地王二麻范例于 `04-chat.html`）
- 待补：其余 4 导购照王二麻范例扩展；图鉴页加"已访问 N 次"标记

### W3 · 桌面端真响应式
- 输出：v1 仅温和放大；v2 做完整响应式（窄屏手机壳 → 宽屏并排聊天+选项区）
- 依赖：无

### W4 · 数值标定（依赖 playtest 结论）
- 输出：破防度初始值、+40/−10 delta、N 轮保底、100/0 阈值的真实取值
- 依赖：**W-playtest（总纲硬闸门）通过**
- 当前：全 `[待测试]` 占位

### W5 · 禁忌词二审（依赖文案扩写）
- 输出：v2 扩写后的全量话术再过一遍禁忌词终审
- 依赖：W1 立绘 + 文案扩写
- 当前：v1 文案已一审通过（`mart-禁忌词终审.md`）

### W6 · 接 brain / 选招制运行时（= M1 解冻）
- 输出：L1.mart 真实字段 + L2 运行时（导购池/招式池/破防度引擎）
- 依赖：**① 总纲 playtest 通过 + ② 外卖 `DATA-STRUCTURE-v1` 字段落定**
- 当前：`mart-L1-datastructure-draft.md` 骨架已备，值待填

## 三、依赖关系图

```
W1 真实立绘 ──┐
W2 对话延续 ──┼─→（并行，无互依）
W3 响应式 ────┘

W-playtest（总纲硬闸门，需真人）
   │
   ├─→ W4 数值标定（吃 playtest 结论）
   │
W-外卖字段（另一 workbuddy 推进，M1 中）
   │
   └─→ W6 接 brain（吃 ①playtest + ②外卖字段）
          │
          └─→ W5 禁忌词二审（吃扩写后文案）
```

**关键路径**：W-playtest + W-外卖字段 都就绪 → W6 解冻 → 真游戏诞生。

---

## 四、优先级逻辑（主理人判断）

1. **W2 对话延续**：已起步，零依赖、立刻增益 playtest，优先收尾（补 4 导购 + 图鉴标记）。
2. **W1 真实立绘**：零依赖，纯美术资产，可与 W2 并行；立绘到货后 v2 视觉质变。
3. **W-playtest**：总纲硬闸门，必须由真人执行；计划已就位（`mart-playtest-plan.md`），等用户招募靶心用户。
4. **W3 响应式 / W4 数值**：playtest 结论驱动，后置。
5. **W6 接 brain**：最后动，严守"等外卖字段落定"铁律，不踩 v1 二义坑。
