## 1. 产品定位

| 项 | 内容 |
|---|---|
| 产品名 | 胡闹导购（whoknow 系列第 2 款） |
| 副标题 | 反骨导购劝你别买 |
| 披着谁的外衣 | 淘宝 / 天猫商品浏览页 |
| 与外卖的本质区别 | 外卖玩 **DRAMA 四阶段推演**（接单→出餐→配送→送达 + 记忆引擎）；mart 玩 **选招制博弈**（用户 vs 反骨导购的说服对决 + 好感度） |
| 核心情绪 | 你越想买，导购越劝退；说服成功 = 爽点（反套路） |
| 战略定位（深化版） | **不是「省钱工具」，是「权力反转 + 情绪代偿」产品**：年轻人在整个消费系统面前是弱者，游戏卖的是「把权力关系反过来」的几分钟掌控感（详见 `docs/mart-产品定位与用户痛点洞察.md`） |
| 双重胜利结构（洞察核心） | **破防态（你撬开他=掌控爽）与反消费胜利态（你没买=省了钱+反套路赢）并列双赢**——归零态不是「你输了」，是「反消费胜利」。详见 `docs/mart-反骨定义与动机设定.md` §五 |

**产品公式（沿用系列 DNA）**：披着[真实电商]外衣 × NPC 戏精人格 × 零卡路里解瘾 = 段子机

## 2. 核心循环

对齐总纲设计支柱 5+1（P1 因你不同 / P2 截图即胜利 / P3 零负担 / P4 戏精由选择触发 / P5 回访靠图鉴 / P6 前 3 秒必有爆点），mart 版：

- **Moment-to-Moment（0–3s）**：进入商品页 / 点「结算」→ **3 秒内**导购闪现第一句毒舌（P6 硬约束）。
- **Session（5–15min）**：浏览 → 加购 → 结算 → 反骨导购闪现 → **选招制博弈**（4 选项轮流怼）→ 好感度攒满 → 导购叹气放行 / 归零劝退。
- **Long-term（回访）**：图鉴收集（导购性格 / 招式 / 隐藏弱点 / 商品梗），**非 gacha 计数**（P5）。

## 3. 选招制博弈状态机（核心特色）

> ⚠️ 这是 mart 的 **L2 运行时**，区别于 waimai 的 `DramaState` 四阶段。mart 不复用 `DramaState`，但**复用其字段命名权威与 chain[] 链表写法**（见对齐清单 §2/§1）。

### 3.1 触发
用户点「结算」→ 导购闪现层弹出（不阻断流程，是博弈起点）。

### 3.2 四选项 + 随机位置
每轮出 4 个选项，**位置随机**防肌肉记忆：
```
① 💪 我需要！（坚定）   ② 📊 我比过价了（理性证据）
③ 🥺 求求了（装可怜）   ④ 🤬 爱卖不卖（以毒攻毒）
```

### 3.3 招式克制矩阵（隐藏弱点）
每个导购性格有**隐藏弱点**——选对招好感 +40，选错 -10 或被喷。示例矩阵（待 playtest 标定数值）：

| 导购性格 \ 招式 | ①坚定 | ②比价 | ③装可怜 | ④以毒攻毒 |
|---|:--:|:--:|:--:|:--:|
| 🔥 毒舌型 | -10（被怼更怒） | +40（用数据打脸最爽） | -10（嫌矫情） | +40（以疯克疯） |
| 🤓 理性型 | +40（自信有理） | +10（本就理性，平手） | -10（情绪化扣分） | -10（无意义对抗） |
| 😴 散漫型 | +10 | -10（嫌麻烦） | +40（心软了） | -10（更不想动） |
| 🧘 鸡汤型 | -10（太功利） | -10（俗） | +10 | +40（反讽戳中） |
| 😈 腹黑型 | +40（顺毛捋） | -10（被看穿不爽） | +40（吃这套） | +10（棋逢对手） |

> 矩阵是 `[PLACEHOLDER]`：具体 delta 与弱点命中规则需 playtest 标定，定义「坏长什么样」：① 同店第 5 次博弈台词/弱点无差异 = 记忆失效，否决；② 任意一轮 4 选项全 -10 或全 +40 = 矩阵崩坏，否决；③ 红线词出现在运行时 = 配置污染，否决。

### 3.4 破防度引擎（反骨版 affinity）
| 字段 | 初始 | 范围 | 说明 |
|---|:--:|:--:|---|
| `affinity`（破防度） | 50* | 0~100 | 反骨版 affinity＝**破防度**：满 100 → 破防态·叹气放行；归 0 → 反消费胜利态·「省钱了，不用谢我」。初值 50 为 v1 占位，反骨建议更低起点（如 30~40），待 playtest 标定 |
| 单轮 delta | — | -10 / +40 | 命中隐藏弱点 +40（人设崩塌高光），踩雷 -10（详见 §3.3 克制矩阵） |
| 记忆分级 | — | first/regular/vip | 复用 waimai `L3.memoryTier` 机制：同一导购第 N 次博弈，台词/弱点池不同（P1 因你不同） |

**状态机流转**：
```
结算 → 导购闪现(首爆点)
  → 轮次循环：
      出 4 选项(随机位) → 用户选招 → 查克制矩阵 → affinity±delta
        ├ affinity >= 100 → 导购叹气：「…行吧，算你赢」→ 下单成功
        ├ affinity <= 0   → 导购：「省钱了，不用谢我」→ 下单被劝退(零卡路里)
        └ 否则 → 下一轮（位置重随机，防记忆）
  → 轮次上限 [PLACEHOLDER]（防死循环；超时默认劝退）
```

### 3.5 记忆分级（复用 waimai L3 机制）
直接复用 `DATA-STRUCTURE-v1` §2.3 / §5.1：
- `first`（首触）：`shopVisitCount === 1`（此处 = 同导购博弈次数 1）
- `regular`（回头客）：`>= 3`
- `vip`（真爱粉）：`>= 10` 或 `affinity[guideId] >= [PLACEHOLDER]`
- 导购台词池按桶分，引擎按玩家在该导购的博弈次数选桶 → 实现 P1「因你不同」。

## 4. 反骨导购性格（5 型 + 隐藏弱点）

| 型 | 阻挠方式 | 隐藏弱点（克制命中 +40） | 典型台词（红线已洗·行动项 A） |
|---|---|---|---|
| 🔥 毒舌型 | 人身调侃（非攻击） | 比价 / 以毒攻毒 | 「这你也下单？上月房租交了吗？」 |
| 🤓 理性型 | 比价 / 挑刺 | 坚定（自信有理） | 「隔壁便宜 50，但你懒得切 App 对吧？」 |
| 😴 散漫型 | 装死 / 拖延 | 装可怜（心软） | 「啊？又要发货？好麻烦…」 |
| 🧘 鸡汤型 | 哲学轰炸 | 以毒攻毒（反讽） | 「你需要的不是商品，是修行」 |
| 😈 腹黑型 | 表面同意实际搞事 | 坚定 / 装可怜（吃顺毛） | 「买吧买吧」→ 然后搞事情 |

> ⚠️ 红线已洗（行动项 A）：原「钱多？」「你这工资也敢买」「人傻钱多」等均已改写。所有台词**必须过 `forbidden_check`（红灯 0 容忍）**，详见对齐清单 §5。

## 6. 商品品类设计

| 品类 | 定位 | 例子 | 戏精空间 |
|---|---|---|---|
| 离谱商品 | 主秀场 | 「能测前任心跳的枕头」「反向伞（雨天淋得更狠）」 | 高——导购吐槽素材富矿 |
| 正常商品 | 锚点真实感 | 口红 / 充电宝 / 拖鞋 | 低——但「导购劝你别买正常货」反差更爽 |

> 原则：零卡路里解瘾。用户不下单也爽（被劝退本身就是段子）。商品是导购博弈的舞台，不是真电商。
