## 0. 为什么测（总纲硬闸门）

总纲行动项 C 是 mart **唯一的发布闸门**：真机 playtest 笑率 + 同店第 5 单差异。在此之前，v1 所有数值 / 话术权重都是 `[待测试]` 假设。**本计划让真人在 `/mart` 真机玩，回收决定 M1 是否解冻的证据**——不测就不能进 Phase 5 制作。

---

## 1. 测试目标与通过线

| ID | 目标 | 通过线 | 否决线 |
|---|---|---|---|
| G1 | 核心循环成立：受试者 ≤3 分钟理解「每轮 4 选 1 → 导购回怼 → 破防度涨跌 → 结算」并走完一局 | 达成率 ≥ 80% | — |
| G2 | 笑率达标：整局至少触发 1 次出声笑 / 截图 | 占比 ≥ 60% | < 30% 否决 |
| G3 | 双重胜利可感：能说清「撬开他」与「被劝退省了钱」是两种赢法，而非「赢/输」 | 能区分者 ≥ 70% | — |
| G4 | 记忆感知（前瞻）：同导购第 2+ 次博弈感知到台词 / 弱点变化 | 采集基线，v1 暂无，记 M1 验收项 | — |

---

## 2. 测试对象（靶心用户）

- **画像**：18–35 岁、被电商 / 外卖客服气过、对「反向消费 / 打工人共鸣」有感触者。
- **样本**：N ≥ 15（熟人内测，质化为主）；其中 ≥ 5 人须为「非项目相关」的外部视角（避免内部人自带理解偏差）。

---

## 3. 测试任务（每人）

- **T1**：打开 `/mart` → 进任意商品 → 点「客服」→ 走完一局**破防态**（试出隐藏弱点，导购叹气发券）。
- **T2**：再来一局 → 故意走**反消费胜利态**（被劝退，归零）。
- **T3（自由）**：截一张最想发朋友圈的图。

---

## 4. 观测指标（回收什么）

| 指标 | 怎么采 | 用途 |
|---|---|---|
| 每轮停留时长 | 录屏时间戳 | 判断选项是「想了想」还是「秒选」 |
| 4 选项选择分布 | 录屏 / 日志 | 哪招最常用；位置随机是否真防肌肉记忆 |
| 笑点触发位置 | 受试者自述 + 录屏 | 哪一幕最炸（首句劝退？人设崩塌？） |
| 截图率 | T3 回收 | 截图即胜利（P2）是否成立 |
| 劝退 vs 放行比例 | 任务结果 | 双重胜利是否均衡可感 |
| 破防度手感 | 问卷 | +40 / −10 / 阈值 100 是否太松 / 太紧 |

## 5. 待测数值清单（v1 占位，测完标定）

> 来源：扫描 `whoknow-mart/dist` 全部页面，以下均为 `[待测试]` 占位。

- **破防度初始值**：50*（反骨建议更低起点，如 30~40）
- **单轮 delta**：命中隐藏弱点 +40（人设崩塌高光）/ 踩雷 −10
- **阈值**：满 100 → 破防态（叹气放行）/ 归 0 → 反消费胜利态（劝退 = 省了钱，非失败）
- **轮次上限**：`[PLACEHOLDER]`（防死循环；超时默认劝退）
- **记忆分级阈值**：first / regular(≥3) / vip(≥10)

---

## 6. 否决标准（坏长什么样）

沿用 `mart-MVP-概念设计-v0.1.md` §3.3 / §8：

1. 同导购第 5 次博弈台词 / 弱点无差异 = 记忆失效，**否决**；
2. 任一轮 4 选项全 +40 或全 −10 = 矩阵崩坏，**否决**；
3. 红线词出现在运行时 = 配置污染，**否决**（见 §7 终审）。

## 7. 质量门：禁忌词红线终审（v1 文案）

已扫描 v1 全部导购台词，对照红线清单（钱多 / 工资 / 人傻钱多 / 真实明星点名）：

- 详见 `docs/mart-禁忌词终审.md`。

## 8. 回收方式 + 周期

- **录屏**（手机 / 桌面均可）+ **5 题简短问卷**（懂没懂 / 笑没笑 / 哪最炸 / 愿不愿截图 / 哪需要改）。
- **周期**：1 周内回收 ≥ 15 份 → 汇总 → 出《v1 Playtest 报告》→ 决策 M1 解冻。
