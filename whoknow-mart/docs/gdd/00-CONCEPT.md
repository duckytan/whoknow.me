## 1. 一句话定位（北极星）

**whoknow-mart = 披着淘宝外衣的反骨导购博弈（选招制）娱乐化 App。**

mart 不卖「省钱」，卖「权力反转 + 情绪代偿」：玩家用话术撬开一个死活不卖的反骨导购，在几分钟里把「消费者在系统面前是弱者」的关系整个反过来，获得「玩家反转了权力关系」的掌控感。商品只是博弈舞台，不下单也爽（零卡路里解瘾）。

> 产品公式（沿用系列 DNA）：披着[真实电商]外衣 × NPC 戏精人格 × 零卡路里解瘾 = 段子机。

## 2. 设计支柱（5+1，mart 实例化）

mart 沿用总纲 §3.1 的 **5+1 设计支柱**（P1–P5 为 5 条，P6 为 +1 硬约束），下方为 mart 语境下的实例化解读。支柱 ID 与总纲对齐，便于跨产品一致性评审。

| ID | 支柱（总纲） | mart 实例化解读 | 实体落点 |
|---|---|---|---|
| **P1** | 因你不同 | 同一导购因玩家博弈历史（第 N 次 / 曾用招式 / 记忆分级）给出不同反应——NPC「记得」玩家 | 复用 waimai `memoryTier`（first/regular/vip），派生源改为「同导购博弈次数」 |
| **P2** | 截图即胜利 | 反骨导购破功那一下 + 双重胜利态文案是天然截图点；戏精弹层保持无水印的干净淘宝伪装 | 戏精弹层（BRAND §7.6）+ 页脚水印分离（api-spec §P0-3 D3） |
| **P3** | 零负担 | 仿淘宝结算流程（不学新操作）、不氪不肝、无 gacha 等级；归零态是「反消费胜利」而非惩罚 | 商品页/结算页复用宿主习惯（BRAND §1） |
| **P4** | 戏精由选择触发，非贴图 | 戏精来自「玩家选招 → 导购回怼」的实时博弈，非预置贴图；4 选项位置随机防肌肉记忆 | 选招制状态机（§4.3） |
| **P5** | 单机也要有回来理由 | 图鉴收集（导购见过 / 招式见过 / 弱点击中 / 吐槽分支），非计数成就 | L4 图鉴（`branchesSeen` 类桶，DATA-STRUCTURE §4.2） |
| **P6** | 前 3 秒必有爆点（硬约束） | 进商品页 / 点结算 → 3 秒内导购闪现第一句毒舌劝退 | 首句轻劝退（反骨定义 §三） |

> ⚠️ **支柱漂移红线**：任何后续 GDD 若削弱 P1（记忆失效）、P2（截图被水印污染）、P3（引入等级/断签）、P4（戏精变贴图）、P6（3 秒无爆点），即为支柱漂移，评审否决（G-1）。

## 3. MDA 框架分析（Mechanics / Dynamics / Aesthetics）

### 3.1 Mechanics（机制层 · 玩家能操作/系统能计算的客观规则）

| 机制 | 说明 | 来源 |
|---|---|---|
| 选招制 4 选项 | 每轮出 4 个招式（坚定/比价/装可怜/以毒攻毒），**位置随机**防肌肉记忆 | MVP 设计 §3.2 |
| 破防度（反骨版 `affinity`） | 0~100；命中隐藏弱点 +40，踩雷 −10；≥100 破防态，≤0 反消费胜利态 | 反骨定义 §六 / L1 骨架 §4 |
| 克制矩阵（隐藏弱点） | 每导购有隐藏弱点招（命中 +40）与踩雷招（−10）；5 型 × 4 招 = 20 格 | MVP 设计 §3.3 / L1 骨架 §3 |
| 记忆分级 | first（首触）/ regular（≥3 次）/ vip（≥10 次或破防度≥阈值）；台词池按桶分 | DATA-STRUCTURE §2.3（mart 派生源改） |
| 双重胜利态 | 破防态（叹气放行）= 掌控爽；反消费胜利态（劝退）= 省了钱，也是赢 | 反骨定义 §五 |
| 商品舞台 | 离谱商品（主秀场，吐槽素材富矿）/ 正常商品（锚定真实感） | MVP 设计 §6 |
| 顶层契约复用 | 信封 6 字段 / `forbidden_check` / 4 级降级 / `ui_meta` 水印 / `Rarity` / `chain[]` | 对齐清单 §1 |

### 3.2 Dynamics（动态层 · 机制涌现出的玩家行为）

- **探索→破防**：玩家盲选招式 → 观察破防度涨跌 → 归纳出该导购隐藏弱点 → 命中 +40 撬开 → 掌控爽感。
- **重复博弈的态度变化**：第 N 次遇同导购，台词池按记忆分级切换（首触毒舌 → 回头客软化 → 真爱粉调侃），玩家感知「被记住」。
- **双重胜利消解负反馈**：归零态被重定位为「反消费胜利」，玩家即便「没撬开」也获得情绪回报，避免失败焦虑。
- **截图传播涌现**：破功金句 + 双重胜利文案天然可截图，驱动朋友圈分享（P2 实体）。
- **防心流崩坏**：保底轮次（N 轮内必破）防「逼半天还不卖」的被耍感；轮次上限防死循环（§6.4）。

### 3.3 Aesthetics（美学层 · 玩家体验到的 8 类乐趣，LeBlanc 框架）

| 乐趣类型 | mart 适配度 | 解读 |
|---|---|---|
| **Sensation（感官/情绪）** | ★★★ | 主打。情绪代偿、出声笑、解压释放 |
| **Fantasy（幻想）** | ★★★ | 权力反转幻想：现实里消费者是木偶，游戏里玩家是操盘手 |
| **Discovery（发现）** | ★★★ | 嘴替（导购替玩家骂真实电商）、预期违背、发现每个导购隐藏弱点 |
| **Challenge（挑战）** | ★★★ | 撬开一个死活不卖的人、找对克制招 |
| **Expression（表达）** | ★★★ | 截图分享朋友圈、零成本社交货币 |
| **Fellowship（关联）** | ★★☆ | 共谋式 solidarity：B/C 动机让导购与玩家同阵营，非欺凌弱者 |
| **Narrative（叙事）** | ★☆☆ | 单局短；跨会话「导购记得玩家」提供弱叙事线 |
| **Submission（沉浸/消磨）** | ★★☆ | 深夜 22 点后 / 工作间歇碎片场景消磨（痛点洞察 §一） |

> **美学结论**：mart 的美学核心是 **Sensation + Discovery + Challenge + Expression** 的四联，与「截图即胜利」「权力反转」定位自洽。

## 4. 动词优先法（verb-first）核心循环

### 4.1 核心动词词表（玩家在 mart 里真正「做」的事）

| 动词 | 含义 | 对应机制 |
|---|---|---|
| **逛** | 浏览商品页（仿淘宝） | 商品舞台（离谱/正常） |
| **点** | 点「结算」触发博弈 | P6 首爆点（3s 内导购闪现） |
| **怼** | 从 4 选项选招怼导购 | 选招制 + 位置随机（P4） |
| **撬** | 命中隐藏弱点，破防度涨 | 克制矩阵 +40 / 破防态 |
| **截** | 截戏精高光发朋友圈 | P2 截图即胜利 |
| **集** | 收集图鉴（导购/招式/弱点/分支） | P5 图鉴 |
| **访** | 换导购/换招回访 | P1 记忆 + P5 回访 |

### 4.2 Core Loop（三时间尺度）

```
Moment-to-Moment（0–3s）
  进商品页/点结算 → 3 秒内导购闪现第一句毒舌劝退（P6 硬约束）

Session（5–15min）
  逛（商品页）→ 点结算 → 导购闪现（首爆点）
    → 选招制博弈（4 选项轮流怼，位置随机）
    → 破防度涨跌 → 循环至破防态/反消费胜利态
    → 截（截图）/ 集（入图鉴）

Long-term（回访）
  图鉴收集（导购性格/招式/隐藏弱点/商品梗），非 gacha 计数（P5）
  → 换导购/换招重玩，感知记忆分级差异（P1）
```

### 4.3 选招制博弈状态机（L2 运行时 · mart 独有，不复用 waimai `DramaState`）

```
[结算] → 导购闪现（首爆点，P6）
  → 轮次循环：
      出 4 选项（位置随机，防肌肉记忆）
        → 玩家选招
        → 查克制矩阵（hiddenWeakness / thunderMine）
        → 破防度 += moodDelta（+40 命中 / -10 踩雷 / +10 平手）
        ├ 破防度 >= 100 → 导购叹气：「…行吧，算你赢」→ 破防态·放行
        ├ 破防度 <= 0   → 导购：「省钱了，不用谢我」→ 反消费胜利态·劝退
        └ 否则 → 下一轮（位置重随机），轮次 < round_cap
  → 轮次达 round_cap 仍未决 → 默认劝退（防死循环）
```

**状态量（L2 运行时，仅内存不落盘）**：`affinity`（0~100）、`round`（本轮次）、`tags`（博弈叙事标签）。
**字段命名对齐权威**：矩阵 delta 用 `moodDelta`；多轮链用 `chain[]` + `next`/`nextWeights`；所有实体用 `id`（L1-T4）。

## 5. 玩家心理学

### 5.1 自我决定论（Self-Determination Theory · 自主/胜任/关联）

| 维度 | mart 如何满足 | 来源 |
|---|---|---|
| **自主 Autonomy** | 玩家自选招式、自定博弈策略；不靠数值碾压，靠「话术选择」决定胜负 | 痛点洞察 §一（权力反转） |
| **胜任 Competence** | 撬开一个死活不卖的人的掌控感；发现隐藏弱点的「看穿了导购底牌」爽感 | 反骨定义 §五（破防态） |
| **关联 Relatedness** | 反骨导购与玩家同阵营：B 报复老板（打工人整资本）/ C 反向温情（为真心劝玩家别买）；共谋式 solidarity，非欺凌弱者 | 痛点洞察 §四 / 反骨定义 §一 |

> ⚠️ **红线关联**：动机绝不能是「系统骗玩家买」（触发逆反心理反弹 reactance backfire）。最稳动机 B（真共鸣）/ C（真为玩家好）（反骨定义 §一）。

### 5.2 心流平衡（Challenge vs Skill）

- **挑战侧**：破防度涨跌 + 隐藏弱点探索，提供适度不确定性。
- **技能侧**：玩家通过策略（试招→归纳弱点）提升胜率，非随机。
- **防心流崩坏**：
  - 保底轮次（N 轮内必破）→ 防「逼半天还不卖」的被耍焦虑（技能够了但系统不放行）。
  - 轮次上限 `round_cap` → 防死循环导致的无聊（挑战无穷但无进展）。
- **平衡判据（待 playtest 标定）**：破防度初始值、+40/−10 delta、轮次上限需调到「多数玩家 5–15 分钟内走完一局且感到掌控」（§10）。

### 5.3 Bartle 玩家类型适配

| 类型 | mart 适配 | 落点 |
|---|---|---|
| **成就者 Achiever** | 图鉴收集、弱点击中、成就解锁 | P5 图鉴 / L4 成就 |
| **探索者 Explorer** | 发现每个导购隐藏弱点、台词分支 | 克制矩阵 / `branches` |
| **社交家 Socializer** | 截图分享朋友圈、零成本社交货币 | P2 截图即胜利 |
| **杀手 Killer** | 用毒舌/以毒攻毒「赢」导购、撬开铁板 | 克制矩阵 +40（以疯克疯） |

> mart 四类全覆盖，偏 **成就 + 社交**（与「截图即胜利」「图鉴回访」支柱一致）。

## 6. 范围分层（scope tiers · MVP / v1 / v2）

> **术语对齐**：原散文档称（截至 2026-07-26 在线）静态 demo 为「v1 原型」、可玩目标为「v2」。本概念文档采用主理人任务给定的 **MVP / v1 / v2** 三层，映射如下：
> - **MVP** = 可玩验证版（= v2 路线图「最小可玩版」目标）。
> - **v1** = 本阶段已备料态（概念冻结 + 全套文档齐备 + 静态 demo 在线）。
> - **v2** = 接 brain 的完整态（冻结至 waimai v2 跑通，总纲 §5）。

### 6.1 MVP（必做 · 纯前端可玩验证版）

| 项 | 范围 | 依赖 |
|---|---|---|
| 核心循环可玩 | 5 导购 × 4 招 × 克制矩阵 + 选招制状态机（§4.3）前端实现 | 无（localStorage 驱动，不接 brain） |
| 破防度引擎 | `affinity` 0~100 + 双重胜利态 | 无 |
| 记忆分级 | localStorage 记每导购博弈次数；第 ≥5 次态度软化（同店第 5 单差异） | 无（W2 已起步，04-chat.html 范例） |
| 截图弹层 | 戏精弹层（导购金句 + 绿底高亮）+ 页脚水印分离 | BRAND §7.6 |
| 图鉴页（基础） | 导购见过 / 招式见过 / 弱点击中 | L4 图鉴结构 |
| 禁忌词常驻 | 静态文案已过终审；运行时若接 brain 须过 `forbidden_check` | 禁忌词终审 |

> **MVP 边界**：不接 brain、不另造大脑、无真实立绘（emoji 占位）、无热搜联动。mart 用静态/手动信封验证乐趣（战略约束 #1）。

### 6.4 否决标准（坏长什么样 · 机检可执行）

沿用 MVP 设计 §8 / playtest 计划 §6 / DATA-STRUCTURE §9，mart 三条否决：

1. **记忆失效**：同导购第 ≥5 次博弈台词/弱点无差异（P1 破裂）→ 否决。
2. **矩阵崩坏**：任一轮 4 选项全 +40 或全 −10（无策略空间）→ 否决。
3. **配置污染**：红线词出现在运行时（任何屏）→ 否决（整包拒绝回退，L1-T1）。

> 附加否决（总纲 L2-C6 发布硬闸门）：断网/L4 降级无水印不崩；同店第 5 单 ≠ 第 1 单。

## 7. 乐趣假说（fun hypothesis · 可证伪）

### 7.1 主假说

> **H0（主）**：在「消费者在系统面前是弱者」的时代痛点下，年轻用户会为「用话术反转权力关系、撬开一个死活不卖的反骨导购」的几分钟掌控感投入注意力与传播行为（截图分享），即便过程不涉及真实交易。

### 7.2 子假说（每条绑定 playtest 指标，可被证伪）

| 编号 | 子假说 | 证伪指标（来自 `mart-playtest-plan.md`） | 通过线 |
|---|---|---|---|
| H1 | 玩家 ≤3 分钟理解核心循环并走完一局 | G1 达成率 | ≥80% |
| H2 | 整局至少触发 1 次出声笑/截图 | G2 笑率 | ≥60%（<30% 否决） |
| H3 | 玩家能区分「破防态」与「反消费胜利态」两种赢法 | G3 区分率 | ≥70% |
| H4 | 双重胜利结构消解「赢=被导购说服下单」隐藏前提，归零态不被感知为「输」 | G3 反向验证 | 归零态自述为「赢」占比高 |
| H5 | 4 选项位置随机真防肌肉记忆 | 选择分布均匀（无单招 >50%） | 分布均衡 |
| H6 | 记忆分级在第 ≥5 次博弈产生可感知差异 | G4 基线（M1 验收项） | 可感知变化 |

### 7.3 证伪机制

- 执行载体：`mart-playtest-plan.md`（N≥15，≥5 外部视角；T1 破防态 / T2 反消费胜利态 / T3 自由截图）。
- 决策闸门：总纲行动项 C（发布唯一硬闸门）。
- **证伪即回炉**：若 G2 <30% 或 G1 <80% 或 矩阵崩坏（§6.4）→ H0 证伪，回炉重设计动机/矩阵/台词，不进 Phase 5 制作。
- 当前状态（截至 2026-07-26）：playtest 未执行，全部数值/话术权重为 `[待测试]` 假设。

### 9.2 mart 自建（无碰撞 · 来自对齐清单 §3 / L1 骨架）

mart 独有结构，命名对齐 §9.3 权威风格，不与 waimai 字段冲突：

```
L1.mart = {
  guides:  Record<guideId, { archetype, motive, hiddenWeakness[], thunderMine[], lineBuckets{first,regular,vip}, rarity, avatar? }>
  moves:   Record<moveId, { label, archetype }>     // 4 招固定，位置随机由 L2 控制
  matrix:  matrix[archetype][moveId] = delta         // +40 / -10 / +10
  affinity:{ initial, min:0, max:100, winState, loseState }
}
L2 运行时 = { affinity(0~100), round, tags }           // 不复用 waimai DramaState(bossMood/riderMorale/totalDelay)
```

### 9.3 字段命名权威遵循（L1-T4）

mart 严格复用：`actor`（非 `speaker`）、`moodDelta`（非 `mood`）、`next`+`nextWeights`、`id`。冲突以 `DATA-STRUCTURE-v1` 胜出。
