## 0. 范围与纪律

本备料为 **MVP 纯前端内容骨架**（不接 brain，战略约束 #1）。所有数值 / 台词 / 价格均为 `[待测试]`，定义「坏长什么样」见 `00-CONCEPT.md` §6.4 / §10。

- **标识符唯一源**：导购 id / 招式 id / `archetype` / 角色色 token / emoji 严格引用 `REVIEW.md` §5 C2 规范表，禁止另起中文型名（D1 漂移已裁定修正）。
- **矩阵模式**：严格 **1 弱点(+40) + 1 踩雷(−10) + 2 平手(+10)**（REVIEW §6 D2 / `02` §7）。L1 draft §1 的「2 弱点+2 踩雷」视为占位待标定，本备料以规范 1+1+2 为准。
- **记忆分级桶**：`first`(=1) / `regular`(≥3) / `vip`(≥10 或 affinity≥阈值)，台词按桶切换（P1 因你不同，`04`）。
- **动机 B+C 双主打**：反骨动机最稳为 B（打工人整资本）/ C（真为玩家好），绝不「系统骗玩家买」（reactance backfire 红线，`00-CONCEPT.md` §5.1）。
- **禁忌词**：全物料过 `forbidden_check`（L1-T1）；价格禁真实数字（红线 #2）；店名/品牌/人名/地名全化名（某宝/某团/某明星/京城）；「智商税」为劝退话术保留（吐槽商品非攻击用户）。
- **表述纪律（L2-C9）**：设计师正文客观；导购台词为引用式角色对白，豁免读者相对代词。

## 5. 禁忌词自检（forbidden_check 接线）

- **红灯（0 容忍）**：本备料所有台词 / 商品名 / 店名 / 价格占位 / 比价素材**不得**含政治 / 色情暴力 / 歧视 / 威胁违法 / 真实信息 / 虚假宣传。Seed 草稿已规避真实品牌（淘宝→某宝/某团）、真实人名（→某明星）、真实地名（→京城）、真实价格数字。
- **黄灯（须化名）**：竞品→某宝/某团；真人→某明星；地名→京城。本备料店名已用「某宝杂货铺 / 某团小店 / 老王不卖铺 / 京城杂货」。
