## 1. 机制（Mechanics）

截图分享是「截图即胜利」（P2）的出口：破防态/反消费胜利态结局卡 + 段子卡为**独立可分享视图**，长按保存/分享，驱动朋友圈传播（Expression 乐趣）。

- **三种卡**（ART-BIBLE §5.4）：结局卡·破防态 / 结局卡·反消费胜利态 / 段子卡。
- **双胜利皆为 success 语义**：两种结局卡都绿框，**反消费胜利态绝非红叉/失败**（§9.1 #5）。
- **水印分离**：页脚 `ui_meta` 水印不进卡（P2 干净淘宝伪装）。

## 2. 数据（Data）

**卡模板（ART-BIBLE §5.4）**：

| 卡 | 触发 | 大标题 | 视觉 |
|----|------|--------|------|
| 结局卡·破防态 | `affinity >= 100` | 「服了，下单吧」 | 白卡 + 绿高亮梗框（`--brand-green` 底） |
| 结局卡·反消费胜利态 | `affinity <= 0` | 「省钱了，下次别来」 | 白卡 + 绿高亮梗框 + 「反套路赢」印章（`--font-brush`） |
| 段子卡 | 导购金句高光 | 金句 | 手写体（`--font-script`）+ 绿高亮底 + 说话者名 `--brand-orange` |

- **尺寸**：移动端基准 `375×N`，圆角 `--radius-xl`，禁水印侵入。
- **对比度**：截屏后社交压缩仍 ≥ 4.5:1（正文 `--fg`#222 on `--bg-2`#fff 或绿高亮底，ART-BIBLE §7.2）。

## 3. 状态（State）

| 态 | 说明 |
|----|------|
| 卡生成 | 02 终止 → 按 WIN_BREAK/WIN_ANTI 选卡 |

| 分享/保存 | 长按保存或分享按钮，独立视图出图 |

## 4. 边界（Boundaries）

- 水印只进页脚，**绝不**覆盖卡（api-spec D3，ART-BIBLE §5.3）。
- 反消费胜利态禁红叉/失败态（双胜利，§9.1 #5）。
- 截图安全区背景高对比纯色/轻渐变，社交压缩后仍清晰（§5.3）。

## 5. 失败模式（Failure modes）

| 失败 | 表现 | 处置 |
|------|------|------|
| 水印误入卡 | 卡被 brain 水印污染 | 红线 P2 → 隔离页脚，卡无水印 |
| 压缩后对比度不足 | 朋友圈压缩看不清 | 强制 `--fg` on `--bg-2`/绿底，禁浅灰小字 |
| 反消费胜利态渲染成失败 | 红叉「你输了」 | 红线 #5 → 视觉自检拒收 |
| 卡无法保存 | 分享 API 不可用 | 降级为长按保存（系统原生） |
