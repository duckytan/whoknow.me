## 1. 机制（Mechanics）

商品舞台是博弈发生的「壳」——玩家先在仿淘宝商品页浏览（**逛**），点「结算」即触发导购闪现与选招博弈（**点** → P6 首爆点 3 秒内导购毒舌劝退）。

- **两类商品**（§4.1 / MVP 设计 §6）：
  - **离谱商品**（主秀场）：荒诞虚构商品（如「能测前任心跳的枕头」），吐槽素材富矿，导购劝退反差最强。
  - **正常商品**（锚定真实感）：口红/充电宝等，走真实电商心智，反差更爽。
- **宿主伪装**：商品列表/详情/结算严格复用淘宝浏览心智（顶栏搜索、`--mart-host` 主色、价格红标、底部 TabBar），保持「一眼像淘宝」。
- **舞台不持有博弈逻辑**：商品仅是「进入博弈的入口」，博弈状态由 02 选招制状态机接管。

## 2. 数据（Data）

`L1.mart` 新增（mart 自建，不触 waimai）：

```jsonc
products: Record<productId, {
  "id": "prod_xxx",                 // L1-T4: 实体用 id
  "name": "能测前任心跳的枕头",      // 戏精占位名，禁真实品牌
  "emoji": "🛏️",                    // 虚构 emoji/渐变占位图，禁真实商品照（ART-BIBLE §9.1 #1）
  "pricePlaceholder": "离谱价",       // 禁真实价格数字（§9.1 #2）→ "¥??"/"离谱价"/"智商税价"
  "shopName": "某宝杂货铺",          // 化名店名（§9.2 化名规则）
  "category": "家居",
  "absurdity": true,                 // true=离谱商品 / false=正常商品
  "guideBinding": "guide_wanger_ma", // 该商品默认绑定导购（见 REVIEW §5 规范 id）
  "rarity": "R?"                     // 复用 Rarity 枚举（v2 立绘/图鉴用）
}>
```

- **价格字段**：仅 `pricePlaceholder`（字符串占位），**绝不**出现数值价格（红线 #2）。
- **店名/品牌**：全部化名（某宝/某猫/某明星/京城/老王不卖铺，§9.2）。

## 3. 状态（State）

| 态 | 说明 | 触发 |
|----|------|------|
| `BROWSE_LIST` | 商品列表（金刚区 + 商品卡） | 进 App |
| `BROWSE_DETAIL` | 商品详情（图+名+价占位+销量灰字） | 点商品卡 |
| `CHECKOUT_TRIGGER` | 点「结算」→ 导购闪现首爆点 | 点结算 CTA（`--mart-host` 填充） |
| → 移交 02 | 进入选招制博弈状态机 | CHECKOUT_TRIGGER 完成 |

## 4. 边界（Boundaries）

- 商品图禁真实品牌 logo / 真实商品照 / 真实价格数字（ART-BIBLE §9.1 #1/#2）。
- 店名/地名/人名全部化名（§9.2 / 黄灯规则）。
- 宿主伪装层除 whoknow 角标（§5.2）外不出现品牌锚色大色块（ART-BIBLE §5.1）。
- 商品数据缺失 → 用内置 seed 占位商品，不阻断进入博弈（对齐 DATA-STRUCTURE §8.1 fallback 精神）。

## 5. 失败模式（Failure modes）

| 失败 | 表现 | 处置 |
|------|------|------|
| 价格数字泄露 | 误填 `¥599` 等真实价 | `forbidden_check` 红灯 → 整包拒绝（L1-T1，见 07） |
| 真实品牌 logo | 误用 Tmall 红猫等 | 视觉红线 #1 → 静态资产自检拒收 |
| 商品配置空 | L1.mart.products 为空 | 注入内置 seed（离谱商品占位），不崩 |
| 导购绑定缺失 | `guideBinding` 无效 | 默认随机绑 5 导购之一，仍可博弈 |

## 7. 契约对齐（Contract alignment）

- **mart 自建**（§9.2）：`products` 为 L1.mart 新增结构，不触 waimai `DATA-STRUCTURE`。
- **复用**：`id`（L1-T4）、`Rarity` 枚举（§9.1）、`ui_meta` 页脚水印（§9.1）、`forbidden_check`（§9.5，价格/店名红灯）。
- **不修改 waimai 文件**（L1-T5 红线）。
- 宿主令牌 `--mart-host`(#FF5000) vs `--brand-orange`(#ff7849) 分区（C3，ART-BIBLE §2.2）。

## 8. 验收（Acceptance）

- [ ] 进商品页 3 秒内导购闪现首句毒舌（P6 硬约束满足）。
- [ ] 商品卡视觉「一眼像淘宝」（宿主皮 `--mart-host` + 白卡 + 价格红标 `--mart-price`）。
- [ ] 结算 CTA 用 `--mart-host` 填充、白字；焦点环 `--brand-orange`。
- [ ] 任意商品无真实价格数字 / 真实品牌 logo / 真实店名（过 `forbidden_check` 红灯为 0）。
- [ ] 点结算后正确移交 02 选招制状态机（不丢上下文）。
