## 0. 范围与纪律

### 0.1 本文件职责

本文件定义 `whoknow-mart` 的**视觉身份基线**，覆盖 BRAND.md 要求的产品视觉九节。本文件在「金克木」冻结期内备料，为 M1 解冻（接入 `whoknow-brain`）提供**可执行的美术规范**，不产出应用实现代码。

### 0.2 与 waimai 的关系（铁律）

`whoknow-mart` 与 `whoknow-waimai` 同属胡闹宇宙，**共享 BRAND.md 双主题 + 品牌锚色 + 字体阵容 + 组件语言**。mart 的「宿主伪装」取**淘宝/天猫橙红系**，`whoknow-waimai/src/style.css` 取**美团黄系**——两者皮不同，但底层令牌、焦点环、戏精弹层、whoknow 角标、无障碍基线**必须一致**。禁止 mart 另起一套视觉系统。具体对齐点见 §8。

### 0.3 战略约束（主理人游承峰拍板）

- **app 优先、大脑自动化后置**：mart 消费 `whoknow-brain` 现有契约（`api-spec.md`），用静态/手动信封，不另造大脑。
- **截图传播驱动**：每个高光交互必须回答「用户会截图发朋友圈吗？」——视觉规范据此把戏精弹层、气泡、结局卡设为「截图安全区」（§5.3）。
- **零负担优先**：界面先问「用户在这个场景习惯怎么操作？」——mart 复用淘宝浏览/详情/结算心智模型（§5.1）。

### 0.4 表述纪律（L2-C9）

本文件使用机器名/角色名/路径/令牌名/章节号指代，禁用读者相对代词与模糊指代（如「你/我们/这个/那个/这里/那里/上面/下面」）。所有引用显式标注来源文件与章节。

## 1. 世界观 / 调性视觉基调

### 1.1 一句话视觉基调

**「披着淘宝皮的反骨嘴替」**：外层是用户熟悉的电商浏览秩序（橙红、卡片、价格、加购），内层是突然炸出来的戏精导购——视觉在「正常电商」与「胡闹反骨」之间制造**预期违背**（对应 `mart-反骨定义与动机设定.md` §四「预期违背 = 总公式」）。

### 1.2 三层视觉情绪模型

| 层 | 名称 | 视觉情绪 | 触发场景 | 参考文件 |
|----|------|----------|----------|----------|
| L1 | 宿主伪装层 | 秩序、熟悉、克制（淘宝浏览感） | 商品列表 / 详情 / 结算前 | `mart-MVP-概念设计-v0.1.md` §1「披着淘宝外衣」 |
| L2 | 胡闹反骨层 | 戏谑、高对比、梗点爆发 | 导购闪现 / 选招博弈 / 破防瞬间 | `mart-反骨定义与动机设定.md` §三「人设崩塌喜剧公式」 |
| L3 | 截图传播层 | 干净、可截、自带梗框 | 结局卡 / 段子卡 / 成就卡 | `api-spec.md` v2.2 D3 水印裁定 |

### 1.3 核心视觉判据（可执行）

1. **伪装可信度**：L1 层在任何截图中必须「一眼像淘宝」——橙红主色、白卡片、价格红标、底部 TabBar，无 woknow 角标以外的品牌侵入（除 §5.3 规定位置）。
2. **反骨爆点对比**：L2 层戏精弹层必须使用「高对比梗框」——手写体台词 + 品牌绿高亮底 + 导购角色色点缀，与 L1 的克制形成视觉断层（截图即传播素材）。
3. **双重胜利皆可视**：破防态（affinity ≥ 100，「服了，下单吧」）与反消费胜利态（affinity ≤ 0，「省钱了，下次别来」）必须**并列两种赢法**，视觉上都是「胜利结局卡」，不得把归零态渲染成「失败/红叉」（对应 `mart-反骨定义与动机设定.md` §五）。
4. **嘴替感可视化**：导购台词承载「你说不出口的他替你说了」的爽点，视觉上用「手写体 + 引号气泡 + 轻微倾斜/抖动」强化「真人嘴替」质感（非系统提示感）。

### 1.4 视觉禁忌基调（先于此文件所有配色）

- 不制造**真实焦虑**（无倒计时压迫、无「再不买就没了」FOMO 视觉、无「你穷」暗示）。
- 不制造**人身攻击**视觉（破防度 meter 不渲染成「智商/财力」标尺；劝退台词视觉不指向用户资产）。
- 不出现**真实品牌 logo / 真实价格 / 真实明星肖像**（详见 §9）。

## 4. 角色 / NPC / 商家视觉语言

### 4.1 反骨导购视觉总纲

反骨导购 = 一个「死活不想把东西卖给你」的客服（`mart-反骨定义与动机设定.md` 〇）。视觉上必须满足五条硬判据（同文件 §二）：立场反转、可破防、戏而不恶、动机自洽、破后反差。

**统一视觉模板（5 型共用）**：

- **头像**：圆形渐变底（角色色 `--role-*`）+ 居中 emoji/符号（🔥🤓😴🧘😈），尺寸 48–56px，外层白边 2px + 轻投影（对齐 waimai `.av` / `.rider-card .av`）。
- **戏精标签 chip**：圆角药丸 + 角色色文字（对齐 waimai `.persona--*` 系列），承载吐槽分类（毒舌/理性/散漫/鸡汤/腹黑）。
- **金句气泡**：白底圆角 + 手写体（`--font-script`）+ 品牌绿高亮底 `rgba(110,218,120,0.08)`（对齐 waimai `.timeline .row .txt`）；说话者名用 `--brand-orange`（对齐 waimai `.who`）。
- **破防高光**：命中隐藏弱点（affinity +40）时，头像/气泡触发 `--shadow-glow-green` 光晕 + 单次抖动（≤300ms，对齐 BRAND.md §8 戏精动效）。

### 4.2 五型导购视觉规格

| 型 | Emoji | 角色色 | 头像底 | 戏精标签 | 动机视觉暗示（化名，禁真实） | 破防高光 |
|----|-------|--------|--------|----------|------------------------------|----------|
| 🔥 毒舌型·王二麻 | 🔥 | `--role-angry`#FF4B10 | 红橙渐变 | 毒舌 | 角标「嘴替」(暗示替用户骂电商) | 绿光晕+抖动 |
| 🤓 理性型·李算盘 | 🤓 | `--role-gentle`#2BB14A | 绿渐变 | 理性 | 角标「算账」(暗示整店铺) | 绿光晕+抖动 |
| 😴 散漫型·赵拖拖 | 😴 | `--role-lazy`#3A7BFF | 蓝渐变 | 散漫 | 角标「想下班」 | 绿光晕+抖动 |
| 🧘 鸡汤型·钱满满 | 🧘 | `--role-philo`#1FB6A6 | 青渐变 | 鸡汤 | 角标「为你好」(C 反向温情) | 绿光晕+抖动 |
| 😈 腹黑型·周暗暗 | 😈 | `--role-weird`#8B5CF6 | 紫渐变 | 腹黑 | 角标「 KPI 怪」(D 考核劝退率) | 绿光晕+抖动 |

> 动机视觉暗示**仅用化名角标文字**（如「整老板」「为你好」），**禁用真实老板肖像 / 真实公司 logo / 真实工资数字**（对齐 `mart-禁忌词终审.md` 红线 1–3 + `mart-反骨定义与动机设定.md` §一红线「动机绝不能是系统骗你买」）。

### 4.3 商家 / 商品视觉语言（舞台，非主角）

- **商品卡**：白底（`--bg-2`）+ `--radius-lg` + 轻阴影，复用淘宝商品卡心智（图 + 名 + 价格红标 + 销量灰字）。商品图用**虚构 emoji/渐变占位**（禁真实品牌 logo、禁真实商品照、禁真实价格数字——见 §9）。
- **商家店招**：圆角方块 logo（对齐 waimai `.shop-card .logo`）+ 化名店名（如「某宝杂货铺」「老王不卖铺」，**某/老王 = 化名规则**，见 §9）。
- **「离谱商品」vs「正常商品」**：离谱商品（如「能测前任心跳的枕头」）是主秀场，视觉可更夸张（大 emoji + 戏精吐槽空间）；正常商品（口红/充电宝）走真实感锚点，导购劝退反差更爽（对齐 `mart-MVP-概念设计-v0.1.md` §6）。

### 4.4 用户（玩家）视觉人格

玩家在 mart 中**不具象为角色**（无玩家 avatar 立绘），仅通过「选招 4 选项」表达立场。视觉上玩家侧用中性 UI 控件（白底按钮 + `--fg` 文字 + `--brand-orange` 焦点环），不与导购角色色混淆。

### 5.3 截图安全区（强制，对齐 api-spec.md v2.2 D3）

- **水印（`ui_meta`）只进环境页脚**（首页/我的订单底部），**绝不覆盖戏精弹层 / 气泡 / 结局卡**。

- 截图安全区背景须为高对比纯色/轻渐变，保证截屏后微信/朋友圈压缩仍清晰（正文 ≥ 4.5:1）。

### 5.4 可截图卡模板（三种，强制执行）

| 卡类型 | 触发 | 视觉规格 | 梗框 |
|--------|------|----------|------|
| **结局卡·破防态** | affinity ≥ 100 | 大标题（`--font-title` 24px）「服了，下单吧」+ 导购头像破功表情 + 破防度满槽绿光 | 白卡 + 绿高亮梗框 |
| **结局卡·反消费胜利态** | affinity ≤ 0 | 大标题「省钱了，下次别来」+ 导购得意/瘫软表情 + 「反套路赢」印章（`--font-brush`） | 白卡 + 绿高亮梗框（**非红叉/非失败**） |

### 5.5 选招制博弈 UI 规格（核心特色，对齐 `mart-MVP-概念设计-v0.1.md` §3）

- **4 选项按钮组**：每轮出 4 个选项，**位置随机**（防肌肉记忆）。按钮白底 + `--fg` 文字 + `--radius-md` + 轻阴影；按压 `scale(.97)`；焦点环 `--brand-orange` 3px（§7）。
- **4 招式视觉标识**（固定语义，位置随机）：
  - ① 💪 我需要！（坚定）→ 图标 💪
  - ② 📊 我比过价了（理性证据）→ 图标 📊
  - ③ 🥺 求求了（装可怜）→ 图标 🥺
  - ④ 🤬 爱卖不卖（以毒攻毒）→ 图标 🤬
- **破防度 meter（affinity 0–100）**：顶部横向进度条，非颜色独载——须带数值（`--font-mono`，如「破防 72」）+ 阶段文案（轻劝/狠劝/松动/破防）。颜色：低值 `--mart-host`、高值 `--brand-green`（成功语义），不渲染成「财力/智商」标尺（§9 禁忌）。
- **命中弱点反馈**：选对招 → 导购头像/气泡绿光晕 + 抖动 + 「+40」浮动数字（mono）；踩雷 → 轻微红边提示（非焦虑，仅游戏反馈）。

## 6. 情绪板 / moodboard 描述

> 以下为候选视觉方向文字描述，供后续美术资产（立绘/图标/动效）对齐。可视化锚点见 `docs/art/MOODBOARD.svg`。

### 方向 A · 「淘宝皮 × 霓虹反骨爆点」（推荐基线）

- **配色**：宿主橙红 `#FF5000` + 白卡 + 价格红 `#FF0036` 构成 90% 电商皮；戏精弹层炸出时，品牌绿 `#6eda78` 高亮底 + 橙红 `#ff7849` 强调 + 紫 `#8b5cf6` 光晕占 10%。
- **字体**：UI 用 Inter/Noto，金句用手写体 ZCOOL KuaiLe，结局卡大标用 ZCOOL QingKe HuangYou。
- **质感**：宿主层扁平干净（无装饰），戏精层加微投影 + 绿光晕 + 手写倾斜，制造「正常界面突然裂开一道胡闹缝」的预期违背。
- **情绪**：熟悉 → 意外 → 爆笑 → 想截图。
- **参考**：waimai 现有浅色皮 + 反骨弹层反差。

### 方向 B · 「干净电商伪装 × 戏精弹层极致反差」

- **配色**：宿主层更克制（近白 `#f7f7f8` + 单一宿主橙红），戏精层用更大面积品牌绿高亮底，让弹层像「从屏幕里探出头的真人」。
- **字体**：金句用手写体 + 轻微旋转（-2°~2°）强化「嘴替」人味。
- **质感**：宿主层近乎无影（极致电商感），戏精层厚重投影 + 绿光晕。
- **情绪**：伪装越真，破防越炸。
- **风险**：戏精层过厚可能破坏「像淘宝」第一眼（需 playtest 校准）。

### 方向 C · 「暖橙红电商 × 品牌绿紫点缀的轻梗向」

- **配色**：宿主橙红为主，品牌绿/紫仅作角标、TabBar 选中、成就光晕的「胡闹徽记」，戏精弹层不炸大色块，走轻量气泡。
- **字体**：同 A。
- **质感**：整体更「正经电商」，梗点靠文案与角色色 chip 而非大色块。
- **情绪**：低调可截，适合首屏信任建立。
- **适用**：MVP 早期信任期，后续向 A 演化。

> **基线裁定**：采用 **方向 A 为默认**，方向 C 用于首屏/列表等信任建立区，方向 B 用于博弈高光弹层（分层使用 L1/L2/L3）。具体由 playtest 笑率与截图率校准。

## 7. 可访问性基线（WCAG AA）

### 7.1 强制清单（对齐 waimai style.css H4 回归 · 2026-07-25）

以下条目为 mart 硬性 QA 基线，**逐条对齐 `whoknow-waimai/src/style.css` H4 回归区块**：

- [ ] **对比度**：正文 ≥ 4.5:1，大字（≥24px / ≥19px 粗）≥ 3:1（BRAND.md §2.5 / §17）。
- [ ] **键盘可达**：所有交互可纯键盘完成，无卡死焦点。
- [ ] **焦点环**：`a/button/input/.tabbar .tb/.entry/.more-links span/.order-card .btn-row .b/.cat-item/.mt-nav__icon` 等可交互元素 → `outline: 3px solid var(--brand-orange); outline-offset: 2px; border-radius: 8px;`（**与 waimai H4 完全一致**）。
- [ ] **触控目标**：所有可点元素 ≥ 44×44px（小药丸按钮/入口项/底部 Tab 用 `min-height:44px` + flex 居中，**与 waimai H4 完全一致**）。
- [ ] **文字缩放**：支持浏览器 200% 缩放不破版（`html { -webkit-text-size-adjust:100%; text-size-adjust:100% }`，**与 waimai H4 完全一致**）。
- [ ] **动效降级**：`@media (prefers-reduced-motion: reduce)` 下全部瞬时（`* { animation:none!important; transition:none!important }`，**与 waimai H4 完全一致**）。
- [ ] **屏幕阅读器**：语义标签（`button`/`nav`/`main`）+ 必要 `aria-label`；装饰图标 `aria-hidden`。
- [ ] **错误预防**：表单有 `<label>` + 实时校验 + 错误文案（非仅靠颜色）。
- [ ] **颜色不独载**：状态变化必带形状/文字/图标辅助（破防度 meter 带数值+阶段文案；选招命中带「+40」数字）。
- [ ] **语言声明**：`<html lang="zh-CN">`。
- [ ] **锚色可读**：锚色仅作点缀/大色块，不承载小号正文。

### 7.2 mart 专属增强

- **截图对比度**：因截图传播为核心（§5.3），戏精弹层/结局卡在「截屏后社交平台压缩」场景下仍须 ≥ 4.5:1——美术基线要求此类卡正文用 `--fg`(#222) on `--bg-2`(#fff) 或绿高亮底，禁用浅灰小字。
- **破防度 meter 无障碍**：进度条须有 `role="progressbar"` + `aria-valuenow` + 可见数值文本，色盲用户可凭数值与阶段文案理解（不依赖颜色）。
- **选招 4 选项**：每个选项按钮含图标 + 文字双标识，色盲/低视用户不依赖图标辨义。

- mart 与 waimai 的视觉差异**仅限宿主皮色与产品专属组件**，其余必须同源。

## 9. 禁忌 / 边界

### 9.1 视觉红线（硬禁，0 容忍）

对齐 `mart-禁忌词终审.md` + `whoknow-brain/docs/禁忌词清单-v1.0` + `mart-反骨定义与动机设定.md` §二「戏而不恶」：

| # | 视觉红线 | 说明 | 依据 |
|---|----------|------|------|
| 1 | 真实品牌 logo | 禁出现淘宝/Tmall/天猫/京东等真实 logo、商标、配色精确复刻到可误认 | `mart-禁忌词终审.md` + 化名规则 |
| 2 | 真实价格数字 | 禁显示真实商品价格（如「¥599」），用虚构/占位（「¥??」「离谱价」）或纯戏精 | 反消费嬉戏，非真电商 |
| 3 | 真实明星肖像 | 禁任何在世真人姓名/肖像/ likeness；用「某明星」化名 + 虚构头像 | `mart-禁忌词终审.md` 红线 4 |
| 4 | 真实工资/资产暗示 | 禁「钱多/工资/人傻钱多」类视觉（如把破防度渲染成「财力条」、劝退暗示「你穷」） | `mart-禁忌词终审.md` 红线 1–3 |
| 5 | 焦虑制造 | 禁倒计时压迫、FOMO「再不买没了」、红叉失败态；归零态必须是「反消费胜利」非失败 | `mart-反骨定义与动机设定.md` §五 |
| 6 | 人身攻击视觉 | 禁指向用户资产/外貌/身份的视觉嘲讽；劝退只调侃 NPC 自身（自嘲最安全） | `mart-反骨定义与动机设定.md` §四 |
| 7 | 真实店铺/地名 | 禁真实店铺名/地名；用「某宝/某猫/京城/老王不卖铺」化名 | `mart-复用契约对齐清单.md` §5 黄灯 |

### 9.2 化名规则（视觉落地）

| 真实指向 | 化名 / 视觉处理 |
|----------|-----------------|
| 淘宝 / Tmall | 「某宝 / 某猫」+ 橙红宿主皮（不精确复刻 logo） |
| 真实明星 | 「某明星」+ 虚构 emoji 头像 |

| 真实价格 | 「¥?? / 离谱价 / 智商税价」等戏精占位 |

### 9.3 视觉红绿灯分级（对齐 `whoknow-brain/docs/禁忌词清单-v1.0`）

- 🔴 **红灯（绝对禁止）**：政治敏感 / 色情暴力 / 歧视 / 威胁违法 / 真实信息（品牌/名人/地名/价格）/ 虚假宣传 → 视觉层同理禁真实标识与误导。
- 🟡 **黄灯（关键词过滤）**：竞品品牌（→某宝/某团）、真实现代人名（→某明星）、真实地名（→京城）→ 视觉用化名+虚构资产。
- 🟢 **绿灯**：天气 / 节日 / 虚构 NPC / 抽象情感 → 自由使用。

### 9.4 运行时校验（mart 同样 0 容忍）

- 所有 mart 视觉文案/资产（导购台词、招式文案、吐槽分支、店名、价格占位）**必须过 `forbidden_check`**（红灯 0 容忍，对齐 `mart-复用契约对齐清单.md` §5）。
- 静态资产（立绘/图标/店招）在产出时即按 §9.1 红线自检；运行时 `red_light_count > 0` → 整包拒绝，走 L4 降级（对齐 `api-spec.md` 降级策略）。

### 9.5 边界示例

- ✅ 合规：导购头像用 🔥 emoji + 红橙渐变底 + 化名「毒舌·王二麻」；商品卡用「能测前任心跳的枕头」+ 🛏️ emoji + 「离谱价」占位；结局卡「省钱了，下次别来」绿框印章。
- ❌ 违规：商品卡出现 Tmall 红底白猫 logo；价格标「¥599」；导购吐槽「你这工资也敢买」；归零态画红叉「你输了」。
