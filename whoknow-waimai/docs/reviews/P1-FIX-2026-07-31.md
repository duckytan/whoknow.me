### D6 · 原生 `alert()` × 3（Major）

原生系统弹窗是最强"出戏"信号，直接击穿真实外壳。全部换成 app 内拟真提示。

| 位置 | 改前 | 改后 |
|---|---|---|
| `OrderView.vue:117` | `alert('本单戏票不支持报销 🎭')` | `showToast('本单戏票不支持报销 🎭')` |
| `ServiceView.vue:51` | `alert(\`已复制：${phone}\`)` | `showToast(\`已复制：${phone}\`)` |
| `SettingsView.vue:10` | `alert('已清空，欢迎重新开演。')` | `showToast('已清空，欢迎重新开演。')` |
| **`SettingsView.vue:7`（漏报项）** | `if (!confirm('确定清空所有数据…')) return` | app 内**底部确认抽屉**：`确定清空` / `再想想` 两个按钮 |

**为什么把没派单的 `confirm` 也修了**：它就在 `clearAll()` 里、在那个 `alert` 上面 3 行，是同一条用户路径上**先弹出**的那个系统框。只换 `alert` 不换 `confirm`，用户照样先吃一个原生系统弹窗——这一项的修复价值会被抵消掉九成。

**实现方式（复用既有样式，未新造轮子、未引入输入框）**：
- 视觉：toast 用 `style.css` 既有 `.ph-toast`（店铺页加购提示同款）；确认抽屉用既有 `.sheet-overlay / .sheet-panel / .sheet-handle / .sheet-title / .sheet-options / .sheet-opt`（订单页地址/备注抽屉同款）。**CSS 零新增。**
- 机制：新增 `src/lib/toast.ts`（纯 TS 消息总线，不 import vue → 可被 node:test 直接单测）+ `src/components/AppToast.vue`（单一挂载点，挂在 `App.vue` 顶层并 `Teleport to body`）。
- **为什么用全局总线而不是每页各写一个局部 toast**：设置页清空数据后会 `router.push('/shops')`，局部 toast 会随页面卸载一起消失，用户根本看不到"已清空"这条反馈。全局挂载点才能跨路由存活。
- **纯点击原则**：确认抽屉只有两个按钮，无任何自由文本输入框。

### 7.1 修一 · 首页"自取"只提示、不切高亮

| 项 | 内容 |
|---|---|
| 文件 | `src/views/HomeView.vue`（`onSegClick`）+ 新增 `src/lib/homeSegment.ts` |
| 改前 | `onSegClick('自取')` 既 `segActive.value = '自取'` 又 `showToast(...)`。结果：高亮跳到"自取"，但下面渲染的仍是外卖首页内容——状态与内容打架，塑料感（D3 那类"一眼仿品"毛刺，只是换了个位置）。死锁虽解，但换来新穿帮 |
| 改后 | 点"自取"**只弹提示，不改 `segActive`**（高亮留在"首页"）。状态与内容始终一致，提示负责解释为什么没切过去 |
| ShopView / OrderView | 那两处的 Tab 是真能切内容的，保持原写法不动 |

**为什么抽纯函数而不是上 `.vue` 挂载测试**：仓库测试运行器是 `node --test`，没有 `@vue/test-utils` / DOM 环境，给 `.vue` 写组件级断言得先引入一套测试依赖——这超出"小修两刀"的范围（属扩范围）。改法同 D1/D2 的"传感器"思路：把"自取不切高亮"的口径抽成 `nextHomeSeg(seg): string | null`——自取返回 `null`，其余透传；组件里仅在返回值非 `null` 时才写 `segActive`。于是"`nextHomeSeg('自取') === null`"就等价于"点自取后 `segActive` 保持原值"，单测钉死这条口径，不硬凑组件测试。

**守门断言（`src/lib/homeSegment.test.ts`，3 条）**：
- `点自取不切高亮（返回 null，调用方不改 segActive）` → `assert.equal(nextHomeSeg('自取'), null)`
- `首页点击正常切高亮` → `nextHomeSeg('首页') === '首页'`
- `非自取分段透传原值` → `nextHomeSeg('外卖') === '外卖'`

### 7.2 修二 · ServiceView 定时器卸载清理（原 N3）
