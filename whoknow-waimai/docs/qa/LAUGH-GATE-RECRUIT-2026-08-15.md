# 胡闹外卖 · 笑率闸门真人实测 · 招募与跑门须知

> 配套执行标尺：`LAUGH-GATE-KIT-2026-07-31.md`
> 本须知供主持人（锡哥）招募 tester 与现场跑门使用，可直接转发给被测人。

## 一、招募谁（5 人）

- 近 30 天点过外卖 ≥ 8 次（熟悉美团流程，但别是同行）
- 没玩过「胡闹外卖 / whoknow.me」这个项目
- 跟项目无关（不是同事 / 开发 / 亲友团里知道内情的）
- 至少含 1 个「冷面型」（平时不爱笑、毒舌那种，笑点硬）
- 年龄跨 2 个段（如 95 后 + 85 后各几个）

> 为什么 5 人不是 3 人：单人权重 33%，3 人里有一个不笑就能翻结论；5 人更稳。

## 二、跑前准备（主持人做）

1. 把「胡闹外卖」用手机**添加到主屏**（去掉浏览器地址栏，像真 App 一样点开）
2. 一对一、没旁人围观（别人在旁边会影响被测人反应）
3. 打开 / 打印记录表（见 `LAUGH-GATE-KIT` §4）
4. 主持人自己**忍住**：不笑、不解释、不指路、不剧透「这是故意搞笑的」

## 三、现场怎么跑

- 每人约 25 单（5 节点 × 组合），一天内跑完，单人约 3 小时
- 主持人只观察、只记**外显反应**（L0 无反应 / L1 嘴角动 / L2 出声笑 / L3 大笑 / L4 掏手机截图发圈）
- L2 出声笑 = 命中爆点，记下来
- 跑门 1 / 2 / 3 直接用这 5 人跑；§6 归因（白纸念段子对照）先别跑，等这轮结论出来再定

## 四、给被测人的一句话邀请（可转发）

> 「哥 / 姐，帮我测个披着美团皮的虚拟外卖小程序，你正常点单玩一遍就行，大概 3 小时，完了请你喝奶茶。手机上加个主屏就能用，纯玩别多想。」

## 五、主持人红线

- 别替被测人点、别解说剧情、别问「好不好笑」（会污染数据）
- 被测人卡住时只说「你随意点」

## 六、收尾

- 每人跑完，主持人把记录表收回，按 `LAUGH-GATE-KIT` 阈值表算 LR / NER / SR / L4 截图冲动中位 / T gift / 爆点密度 GD
- 5 人全跑完即出闸门结论；过门再进 P2
