# 🎨 视觉评估报告 · 胡闹外卖 v2（whoknow-waimai）

> **评估人**：art-auditor（林绘澄，游戏美术与视觉表现指导）
> **评估对象**：BRAND.md v1 + design-tokens.css + 原型 prototype/ 12 页
> **对齐文档**：GDD-v2-2026-07-24.md、胡闹宇宙总体设计方案 v3
> **评审强度**：lean / solo（1 人项目，Vercel 海外部署，纯广告）
> **日期**：2026-07-25
> **结论**：⚠️ **CONCERNS**（策略自洽，但原型为「前品牌」状态，品牌层与无障碍为重建硬门槛）

---

## 0. 一句话结论

原型**用实力验证了「用户习惯零摩擦」（8 分美团皮）这半条策略**——刷、点、结算动线高度贴合美团。但它是**「11 分美团皮 + 0 分锚色」**：BRAND.md 的「锚色点缀 + 戏精人格」那半条，**在 12 页原型里几乎完全没落地**（锚色近乎缺席、无 Logo、无戏精弹层、无手写体、无截图边框、无水印）。叠加若干无障碍回归（锁缩放、无焦点环、无动效降级），这些必须在重建时作为**一级硬要求**，不能等「接完 tokens 再说」。

---

## 1. 视觉识别一致性

**策略本身自洽**：BRAND「双主题 + 品牌锚色（绿 #6eda78 / 橙 #ff7849 / 紫 #8b5cf6）」与 GDD「8 分美团皮 + 锚色点缀」无冲突，且 design-tokens.css 已就绪、可 `@import`，是干净的执行基础。

**原型与规范的落差（核心问题）**：
- 原型 CSS 头注释自陈：「高仿美团外卖设计系统 v2 · 主色美团黄 #FFD100｜价格红 #FF4B10 · 基于真实美团截图逐像素校准」。整份 `meituan.css` 用自有变量（`--mt-yellow`/`--mt-price`），**完全未引用 `--brand-*`**。
- 锚色在 12 页中的实际出现：**绿**仅用于金刚区「蔬菜水果」图标底色（巧合的品类色，非品牌化）；**紫**仅用于哲学 persona pill 文字色 `--role-weird:#8B5CF6`；**橙 #ff7849 完全缺席**（原型用的是美团味 `#FF7E45`，非品牌橙）。
- BRAND §2.3 / §12.5 要求锚色必须出现在**导航栏 Logo、戏精弹层、品牌化按钮、成就徽章**——原型**四处皆无**：无 whoknow 字标、无品牌按钮、成就页用美团黄软底、戏精弹层未成形。
- → 「一眼认出是 whoknow」的承诺在原型阶段**不成立**。

**判定：CONCERNS**。策略对、令牌齐，但原型未消费令牌，属「已知且可闭环」的缺口。

## 2. P6 首屏爆点的视觉落地可行性

GDD §7 列 8 个关键屏首爆点。抽查 4 个核心页（首页/店铺/确认订单/订单详情）+ 全 CSS 组件库：

| 屏 | 首爆点 | 原型状态 | 支撑组件 |
|---|---|---|---|
| 首页 | persona 标签 | ✅ 已渲染（暴躁/哲学 pill） | `.persona` 存在，但用美团色系 |
| 店铺 | 暴躁老板气泡 | ❌ **未渲染** | `.boss-bubble` 样式已在 CSS 定义（line 420）但**未接进 shop.html** |
| 确认订单 | 备注预览 | ❌ **缺失** | 仅「请填写您的要求」，无「老板会因备注发疯」预览（GDD §13 明确要求） |
| 订单详情 | 骑手气泡 + 送达彩蛋 | ✅ 已渲染（雷速飞气泡 + 纸条彩蛋） | 但用系统字体，**无手写体、无锚色高亮底、无截图梗框** |

**缺视觉规范（仅文字描述）的爆点**：
- 截图边框（§5.4 绿/橙/紫 3 款）：**全原型缺失**，戏精弹层/气泡/结局卡无「梗框」。
- 手写体金句（§14.4 ZCOOL KuaiLe / Ma Shan Zheng）：雷速飞气泡、彩蛋、老板气泡均为系统字体，承载截图传播第一素材的字体**缺失**。

**判定：CONCERNS**。4 屏中 2 屏首爆点直接缺位、2 屏有但材质弱（无手写体/边框），且 4 个爆点中 3 个缺视觉组件规范。

## 3. 截图传播钩子 + 水印边界

- **水印（§9.5「脑在工作」页脚）**：**全 12 页原型均未实现**，含本应承载它的首页。裁定「只进环境页脚、不覆盖戏精截图片」在视觉上**无法验证**——因为水印本身还没画。
- **边界可执行性**：戏精爆点（老板气泡/骑手彩蛋/结局卡）是内联内容、非常驻浮层，天然不带水印；只要水印严格锁在固定 ambient 页脚（非 sticky 覆盖层），截图爆点帧即可干净。**边界逻辑可行，但须重建时以「水印绝不进入戏精弹层/气泡/结局卡」为硬验收项**（GDD §14 D3 待确认项）。
- **截图材质**：缺梗框 + 缺手写体 → 用户截的图只是「美团截图 + 一行普通字」，传播力薄弱，P2「截图即胜利」落点被削弱。

**判定：CONCERNS**。

## 4. 无障碍（WCAG AA）执行层缺口

对照 BRAND §17 十条硬性清单，原型现状：

| 条目 | 现状 | 判定 |
|---|---|---|
| 对比度 ≥4.5:1 | 弱文字 `--mt-text-3:#999999` 置于白卡（约 2.8:1）用于占位/副文 | ❌ FAIL（小字） |
| 键盘可达 / focus-visible | 全 CSS **无任何 `:focus-visible` / outline** | ❌ FAIL |
| 文字缩放 200% | 多页 `user-scalable=no` / `maximum-scale=1`（home/order 等）锁缩放 | ❌ FAIL（阻断） |
| 触控 ≥44px | 图标按钮 28px、加号按钮偏小，未强制 44px | ⚠️ 风险 |
| 动效降级 | 全 CSS **无 `@media (prefers-reduced-motion)`** | ❌ FAIL |
| 颜色不独载 | persona 颜色+文字并存（ok）；状态多靠色 | ⚠️ 部分 |
| 语言声明 | `<html lang="zh-CN">` 全页具备 | ✅ |
| 锚色可读 | 锚色未承载小字（moot） | ✅ |

**判定：FAIL 级回归**。对 Vercel 公开广告产品，锁缩放 + 无焦点环 + 无动效降级是发布门槛级问题，必须在 M1 重建时清零。

## 5. 美术风险等级清单 + 结论

### 🔴 P0（重建 M1 一级硬门槛，不解决不许进 M1）
- **P0-a 令牌未接入**：原型仍用 `meituan.css` 硬编码，未 `@import` `design-tokens.css`。重建首步必须切换，否则锚色无法落地。
- **P0-b 锚色近乎为零**：绿仅品类图标、紫仅 pill 文字、橙完全缺席；Logo/戏精弹层/品牌按钮/徽章无锚色 → 「认出是 whoknow」失效。须按 BRAND §2.3/§12.5 强制注入四处。
- **P0-c 无障碍回归**：`user-scalable=no` 锁缩放、全无 `focus-visible`、全无 `prefers-reduced-motion`、44px 未强制、#999 弱文字对比度不足。公开产品发布门槛。
- **P0-d 店铺首爆点缺位**：进店无任何老板气泡（P6 硬约束），`.boss-bubble` 样式已定义但未接 shop.html。
- **P0-e 确认订单备注预览缺位**：无「老板会因备注发疯」预览，P2/P4 的前端钩子缺失，戏精只在后端。

### 🟠 P1（M1–M2 必须补）
- **P1-a 截图边框**（绿/橙/紫 3 款）与梗框缺失（§5.4/§14.4）。
- **P1-b 手写体金句**（ZCOOL KuaiLe / Ma Shan Zheng）未落地。
- **P1-c 水印**全原型未实现，须补且以「只进环境页脚」硬验收。
- **P1-d persona 色**用美团价红 `#FF4B10`（angry），须重映射避免与美团撞色、对齐锚色语义。
- **P1-e 竞品名泄漏**：checkout/order 出现「美团红包/美团支付/微信支付/支付宝/工行」，GDD §12 要求代称「某团/平台」，重建清单须显式拦截。
- **P1-f 全 12 页逐屏核对** P6 清单（购物车零卡提醒、我的订单图鉴、Feed 彩蛋卡、客服抢麦未抽查，建议全覆盖）。

### 🟡 P2（建议优化）
- **P2-a** 食物图仍 emoji 占位（§12 禁 emoji 穿帮），截图传播会露馅。
- **P2-b** 锚色光晕 / 戏精弹簧动效（§16）原型无体现。
- **P2-c** 主站暗色门面 ↔ 外卖浅色 App 的 Logo 角标过渡（§12.5）M1 定稿。

## 6. 给主理人游承峰的结论

**CONCERNS** —— 不 FAIL（品牌策略自洽、令牌已就绪、美团皮零摩擦已验证，缺口可闭环），但**绝不能「先按美团皮重建、品牌层后补」**。M1 重建须把「令牌接入 + 锚色四点注入 + 无障碍清零 + P6 两屏爆点接线 + 截图边框/手写体/水印」列为与逻辑同级的硬完成项，否则 v2 上线仍是「另一个美团换皮」，丢掉了唯一差异点。
