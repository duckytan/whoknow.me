## 二、构建 & 部署

1. **本地构建**：`npm run build` → 生成 `dist/`。
2. **推代码（你本人来，沙箱凭据墙推不上去）**：
   在能登录 GitHub 的终端：
   ```bash
   git fetch origin          # 先看远程有没有你本地没有的东西
   git pull --rebase origin main   # 若有，先对齐，别强推
   git push origin main      # 推上去（含本次 P2 commit 6bc45c7）
   ```
   > 本地目前领先 `origin/main` 94 个提交未推，push 前务必先 fetch 对齐。
3. **Vercel 自动部署**（整仓托管）：push 后 Vercel 自动跑 build 并发布；`/waimai` 路由指向 `whoknow-waimai/dist`。
4. **确认线上是新版**：打开线上 `/waimai`，走一单看骑手有没有环境旁白（如公厕「这味儿，导航都给我标了景点」），有 = 新版生效。
