## §2 “灵魂”差距分级

按「操作即感知是美团」的影响排序。

### P0 · 灵魂级（不做就不像美团）

1. **全局底部 Tab Bar 范式** — 美团四 tab（外卖/神券/订单/我的）+ 选中态黄色图标/文字。当前 emoji+橙色圆点选中既不像美团，首页 `/` 也没有正确高亮。
2. **首页顶部导航 + 金刚区 + Feed 结构** — 三段导航、定位地址、搜索、10 宫格、神抢手、附近商家/特价外卖 Tab。当前首页缺少 80% 的框架。
3. **店铺详情页完整范式** — hero 大图、外送/自取切换、分类侧栏、横向促销、菜品卡片（图+标签+原价/现价+大加购）。当前是平铺 emoji 列表。
4. **确认下单页完整表单** — 地址/时间、价格明细、支付方式、发票、权益、粘性结算栏。当前仅为 chip 表单+按钮。
5. **订单历史页范式** — 黄色头部、顶部 Tab、商品图、多按钮操作行。当前为简单卡片列表。

### P1 · 手感级（做了才像）

- 首页：定位地址行、神抢手横向滚动、特价外卖 Tab。
- 商家列表：筛选 chip 行、红包横幅、卡片右侧黄色 CTA。
- 店铺页：菜品真实图/标签/原价划线、大家都在说好横向区。
- 客服页：订单信息卡 + IM 气泡 + 快捷回复 + 底部输入栏。
- 下单页：粘性结算栏的视觉比例与动效。
- 状态栏：真实系统状态图标（信号/WiFi/电池/时间）。
- 路由：首页 `/` 与 TabBar「外卖」选中态对应； `/order` 下隐藏底部 TabBar 或确保结算栏不被遮挡。

### P2 · 锦上添花

- 金刚区自定义插画图标（替换 emoji）。
- 页面转场动效（淡入+轻微上滑）。
- 卡片 hover/press 微交互。
- 搜索历史与联想词。
- 真实菜品图片资源。
- 骨架屏与加载态。

## §3 P0 详细改造规格

### P0-1 全局底部 Tab Bar 范式

**现状问题**
- `TabBar.vue` 当前四项：`🛵 外卖 → /shops`、`📋 订单 → /orders`、`⭐ 成就 → /achievements`、`🤡 我的 → /profile`。
- 选中态为 `--brand-orange` 圆形背景，与美团黄色选中态不符。
- 首页 `/` 没有对应 Tab，导致在首页时没有任何 tab 高亮。
- “成就”不是美团 TabBar 范式，美团第二 tab 为“神券”。

**目标形态**
- 四 tab：**外卖 / 神券 / 订单 / 我的**。
- 图标：未选中为灰色线性图标；选中为黑色文字 + 黄色填充/高亮图标（参考 cuts/2982068..._p3.png）。
- 首页 `/` 对应“外卖”高亮。

**具体改动点**

| 项 | 文件/位置 | 视觉规格 | 交互规格 |
|----|-----------|----------|----------|
| Tab 项 | `src/components/TabBar.vue` | 4 等分；图标区 24–28px；文字 11px；未选中 `--mt-text-3` / 选中 `--mt-text`；选中图标背景改用 `--mt-yellow` 或黄色填充样式，移除橙色圆形。 | `router-link` 目标：`/`, `/coupons`（或复用 `/achievements`）, `/orders`, `/profile`；active 判定 `route.path === it.to` 或 `startsWith`（除 `/` 外）。 |
| 容器 | `src/style.css` `.tabbar` | 保持 `position:fixed`、`bottom:0`、`max-width:var(--maxw)`、`z-index:10`、`safe-area-inset-bottom`；背景 `#fff`；顶部 1px `var(--mt-line)`。 | 点击后 100ms 内 `scale(.97)` 反馈。 |
| 首页高亮 | `src/router/index.ts` + `PhoneFrame.vue` | 无新增视觉，只需路由对应。 | 首页 `/` 对应“外卖”；`isActive('/')` 仅在 path 严格等于 `/` 时高亮，避免所有以 `/` 开头的路径都被点亮。 |
| “神券”视图 | 新建或复用 `src/views/AchievementsView.vue` | 列表卡片式，顶部黄色/白色头，标题“胡闹神券”或“神券 · 成就”。 | 复用现有成就数据，但用“神券”包装；路由建议新建 `/coupons` 指向原 `AchievementsView` 或新组件，由 engineering-lead 决定。 |

**与现有架构衔接**
- 不改 `sliceDrama`、`DramaChat`、`MapTrack`、`PushNotifier`。
- 确保 `.phone` 的 `padding-bottom:56px` 与 `.tabbar` 高度一致；购物车栏 `.cart-bar { bottom:56px }` 继续生效。

## §5 不动清单

以下红线在本次打磨中**明确不改**，engineering-lead 实施时需绕过：

1. **胡闹内核内容**：对话文案、水印文案、荒诞台词、NPC 人设、成就名称保持现有戏精风格。
2. **`sliceDrama` 引擎逻辑**：输入参数、事件流、分支计算、分支名、概率逻辑不动。
3. **纯点击原则**：地址/备注/时间/券等选择继续用 chip/picker，不引入自由文本输入框。
4. **红线门控**：`runForbiddenCheck` 调用与 `isDev` 显示逻辑不动。
5. **品牌锚色点缀策略（BRAND.md §12.5）**：`--brand-green` / `--brand-orange` / `--brand-purple` 仅用于 Logo 角标、戏精弹层、品牌按钮、成就徽章；不用于替代美团功能色（如外卖黄 `--mt-yellow`、价格红 `--mt-price`）。
6. **核心数据模型**：`shops.ts`、`dishes.ts`、`cart.ts`、`memoryStore.ts` 的字段语义不动；仅允许扩展可选字段（如 `category`、`flash`）。

### 建议实施顺序

每步可独立验证，建议按以下顺序：

1. **P0-1 TabBar**：影响全局，先让“外卖/神券/订单/我的”骨架正确，且首页 `/` 能高亮。
2. **P0-2 首页结构**：三段导航、定位、金刚区、神抢手、Feed Tab。完成后首页即具备美团“第一眼”骨架。
3. **P0-3 店铺详情**：分类侧栏、菜品卡片、购物车栏。完成后核心点餐流程更像美团。
4. **P0-4 下单表单**：地址/时间/价格/支付/权益/粘性结算栏。完成后下单页具备美团“灵魂”。
5. **P0-5 订单历史**：黄色头部、Tab、商品图、操作按钮行。
6. **P1 项**：按 P1-1 → P1-4 → P1-3 → P1-5 顺序补齐手感。

### 风险点与取舍

| 风险 | 影响 | 建议处理 |
|------|------|----------|
| **TabBar 与首页路由冲突** | 当前 `TabBar` 第一项指向 `/shops`，首页 `/` 无高亮。 | 将第一项改为 `/`；在 `HomeView` 中保留“去胡闹外卖选店”按钮，或把 `/shops` 内容合并到首页 Feed。 |
| **TabBar 与下单页粘性底栏重叠** | 美团下单页无 TabBar，我们的 `PhoneFrame` 默认显示。 | 在 `/order` 路由配置 `meta: { hideTab: true }`，`PhoneFrame` 读取后隐藏 `TabBar`；同时 `.pay-bar` 底部无需再避开 56px。 |
| **购物车栏 `.cart-bar` 与 TabBar z-index** | 当前 `.cart-bar z-index:9`、`.tabbar z-index:10`。 | 若保留 TabBar 不变；若下单页隐藏 TabBar，ShopView 的购物车栏仍需 `bottom:56px`。 |
| **DramaChat / MapTrack / PushNotifier 被覆盖** | 结果态 `.order-detail` 包含地图、聊天、推送，z-index 需保持合理。 | `PushNotifier` 已 Teleport 到 body，z-index 1000 不受影响；地图区域 `.map` 保持 `z-index:0~5`；结算栏/TabBar 不要高于 `z-modal` 弹层。 |
| **纯点击原则 vs 美团长表单** | 美团下单页有大量输入型 cell（地址、备注、餐具、发票）。 | 所有 cell 点击后弹出 chip/抽屉选择器，不唤起键盘；视觉上像美团，交互上仍零输入。 |
| **品牌锚色与美团黄色冲突** | 若过度使用 `--brand-orange` 会偏离美团皮。 | TabBar 选中态改用 `--mt-yellow`；品牌锚色仅用于 whoknow 角标、戏精弹层、成就徽章。 |
| **数据字段不足** | 店铺/菜品缺 `category`、`flash`、`originalPrice` 等。 | 允许扩展可选字段并给出默认值；不修改现有字段语义。 |

### 验收信号

完成 P0 后，用户应能在不看 Logo 的情况下，通过以下操作感知到“这是美团”：

- 打开首页 → 看到三段导航 + 定位 + 金刚区 + 神抢手 + 商家 Tab。
- 点击底部 Tab → 四 tab 切换节奏与美团一致。
- 进入店铺 → 看到大图 hero + 分类侧栏 + 菜品卡片 + 购物车栏。
- 去结算 → 看到地址/时间/价格/支付/权益 + 底部黄色结算条。
- 查看订单 → 看到黄色头部 + Tab + 商品图 + 再来一单。
