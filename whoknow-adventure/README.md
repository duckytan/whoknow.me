## 零、它在胡闹宇宙里的位置

| 产品线 | 目录 | 形态 | 上线方式 |
|---|---|---|---|
| 胡闹外卖 | `whoknow-waimai/` | Web App | Vercel `/waimai` |
| 胡闹导购 | `whoknow-mart/` | Web App | Vercel `/mart` |
| 胡闹控制中心 | `whoknow-brain/` | AI 后台 | 不上台 |
| **胡闹冒险** | **`whoknow-adventure/`** | **纸笔实体（可打印）** | **不部署** |

三条与另外三条不同，先写死，避免以后按 Web 项目的习惯误操作：

1. **不参与 Vercel 部署** —— 没有 `dist/`、没有构建命令，**不要动 `vercel.json` 加路由**。
2. **不需要内部链接相对路径规则** —— 产物是 A4 打印件，不是网页。
3. **内容不经 `forbidden_check` 闸门** —— 那是段子内容管线（brain → waimai/mart）的规矩，桌游文案走人工审核即可。

但**品牌层仍然共享宇宙**：命名沿用 `whoknow-*` 前缀、对外统一叫「胡闹冒险」、视觉可复用 `BRAND.md` 锚色（绿 `#6eda78` / 橙 `#ff7849` / 紫 `#8b5cf6`）。

**品牌一句话**：胡闹冒险 = 一本册子 + 一支笔，把「运气」从骰子手里抢回来，交还给你的手。

## 一、这个项目的真实成本（先看这个）

主理人想做独立纸笔地城桌游。先把账算清楚：

| 工作项 | 单件成本 | 数量 | 小计 |
|---|---|---|---|
| 关卡设计（画地图 + 定啊哈点） | 1–2 h | 50 关 | 75 h |
| 关卡校准（每关至少试玩 3 遍调数值） | 2–3 h | 50 关 | 125 h |
| Boss 关设计（动作设计 + 靶型设计） | 8 h | 7 个 | 56 h |
| 数值 / 经济系统调平 | — | — | 30 h |
| 排版、图例、说明书 | — | — | 20 h |
| **合计** | | | **约 300 小时** |

按每天投入 2 小时算，**4–5 个月**。

**结论：这不是资源问题，是工时问题。** 300 小时是省不掉的，只能靠"分批做、边做边验证"来降低风险——所以才有现在的 5 关验证版。

## 二、锁死的部分（不要动）

这些是产品的地基，**任何改动都会让前面的试玩数据作废**：

1. **命中判定规则**（所有靶一致）
   - 正中靶心 = 完美规避，双方都不掉血
   - 内圈 = 怪物掉 1 血
   - 外圈 = 怪物掉 2 血
   - 深灰段 = 触发怪物特殊能力，本次攻击无效
   - 划到靶外 = 玩家损失该怪伤害值

2. **靶的难度旋钮只有三个**
   - 外圈半径（容错）
   - 靶心占比（完美规避的爽度）
   - 深灰段角度（惩罚频率）

   **不要每关改命中规则**——玩家学不会，手感就废了。

3. **攻击条距离**：统一为靶心下方 32mm。这个距离决定难度，别乱调。

## 三、七章移动规则库（草案，待设计）

每章换一套移动规则，是这游戏的"章节感"来源。已做第一章，其余待开发：

| 章 | 主题 | 移动规则 | 状态 |
|---|---|---|---|
| 1 | 冰原 | **滑行**：选方向后一直滑到撞墙/撞怪才停 | ✅ 已做 5 关 |
| 2 | 草原 | **限步**：一次走 1–4 格，撞到障碍才能转向 | 待做 |
| 3 | 森林 | **限步 + 撞停**：走 1–4 格，撞障碍即停且不能再动 | 待做 |
| 4 | 洞穴 | **盲点**：闭眼点一个格子，用最短路径自动走过去（会点歪） | 待做 |
| 5 | 墓地 | **限步 + 强制战**：停在墓地旁强制与亡灵战斗 | 待做 |
| 6 | 荒野 | **自由步**：走 1–4 格，可中途任意转向（比草原宽松） | 待做 |
| 7 | 地城 | **双层**：上层踩到走过的格子跌落到下层对应位置 | 待做 |

**排序原则**：把最简单和最出彩的放前面，玩家评价差的规则（如盲点）放中段当调剂。

## 四、Boss 动作库（手感动作集）

Boss 关的爽点不在血量，在**"这次要用手做一件不一样的事"**。候选动作：

| 动作 | 做法 | 难度来源 |
|---|---|---|
| 切割 | 一笔划线，要穿过多个部位且落在切割区内 | 精度 |
| 连点 | 闭眼沿路径连点一串，每回合环境恶化一格 | 节奏 + 精度 |
| 非惯用手 | 强制换手瞄准 | 肌肉记忆失效 |
| 拉远 | 攻击条距离翻倍 | 容错骤降 |
| 盲走 | 不看地图走 N 步 | 记忆 + 空间感 |
| 连击 | 一笔画过三个分离靶（靶纸 C 型） | 连续性 |
| 限时 | 每回合岩浆/水位上涨一格，逼你加速 | 压力 |

**每章 Boss 至少用 2 个组合**，别只用血量堆。

## 六、造关 checklist（每关必过）

- [ ] **这一关的「啊哈」是什么？** 一句话说不出来 → 重做
- [ ] 有没有**至少两条路**：一条稳（少星但安全）、一条贪（多星但冒进）？
- [ ] 会不会出现**死锁**（滑到某处后无路可走 / 无法回头）？滑行规则尤其容易中招
- [ ] 三星阈值**试玩过 3 次**吗？没玩过就别定稿
- [ ] 单关时长在 **10–15 分钟**吗？
- [ ] 玩家有没有机会**因为手抖把算好的局玩崩**？（有，才好；但要让他觉得"是我手菜"而不是"游戏坑我"）

## 七、试玩记录表（照抄到你的笔记本）

每关试玩后填一行：

```
关卡：第 __ 关
第 __ 次试玩 ｜ 用时 __ 分钟
移动 __ 步 ｜ 击杀 __/__ ｜ 失血 __
啊哈出现了吗：有 / 没有 / 没感觉
最爽的一刻：
最烦的一刻：
是否想再来一局：想 / 不想 / 随便
阈值需要怎么调：
```

**「是否想再来一局」这一栏是核心指标。** 连续 3 关都填"不想"，就该停下来重新审视机制，而不是继续做关卡。

## 八、已知风险

| 风险 | 说明 | 应对 |
|---|---|---|
| **打靶手感不成立** | 最大风险。不爽的话 50 关全白做 | 先做 5 关验证，不爽就停 |
| 关卡产能不足 | 300 小时是硬成本 | 分批做，每章做完先自己玩一遍再开下一章 |
| 消耗品悖论 | 做成实体，玩家会自行覆膜 → 只买一本 | 要么接受（走口碑/续作），要么做电子版（但精度是电子版的天敌） |
| 闭眼机制排斥部分玩家 | 视力 / 手部稳定性差异会被放大 | 提供一个"不闭眼"的降级模式 |
