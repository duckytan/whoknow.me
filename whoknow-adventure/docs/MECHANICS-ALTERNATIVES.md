# 胡闹冒险 · 替代机制库（不用"铅笔盲点命中区"）

> 2026-09-06 ｜ 目标：绕开 PBA / 屁兜冒险的 draw & jab 机制，用**日常学生/办公室文具**找出我们自己的核心手感
> 背景：闭眼打靶已被 PBA 与屁兜占死，且它有硬伤（依赖印刷精度、闭眼排斥手抖与视力差玩家）。绕开它是机会不是妥协。

---

## 零、三条筛选规矩（不合规的方案直接淘汰）

1. **结果必须是看得见的物理事件**——要有"啊"的一刻（弹飞了、擦破了、滚出界了）。纯心智推理不算。
2. **技巧必须能练**——玩家要能感觉到自己变强。否则就是"掷骰子换皮"，不如直接掷骰子。
3. **不依赖印刷精度**——判定靠"停在哪格""撞到没有"，而不是"戳中第几圈"。这是屁兜的命门，我们必须绕开。

---

## 一、投射类（手感血统最老，最稳）

### 1. 弹射 Flick ★★★ 首推
- **文具**：笔帽 / 橡皮 / 回形针 / 硬币（全部零成本，口袋里就有）
- **玩法**：册子里印一块"战斗盘"（格子 + 怪物 + 障碍 + 坑洞）。把笔帽放发射线上，用手指或尺子弹出去。
- **判定**：撞到怪 = 伤害；撞到障碍 = 反弹；掉进坑 = 失手；飞出盘外 = 失手。
- **爽点**：**连击**。一次弹射撞完 A 怪反弹再撞 B 怪，像打台球——这是闭眼打靶结构上做不到的。
- **技巧**：力度 + 角度 + 利用反弹走位。上限极高，真的能练出肌肉记忆。
- **为什么优于打靶**：
  - ① 不怕印刷误差（判定"停在哪格"，格子大就行，不需要精确同心圆）
  - ② 睁眼操作，无障碍好太多（手抖的人可以近距离弹、轻弹）
  - ③ **弹飞出界本身就是笑点**，天然适合录屏传播，正中"胡闹"人格
  - ④ 小时候上课弹笔帽是集体记忆，动作自带梗
- **坑**：需要平整桌面（便携性略降，但笔帽可夹在书里）；要防作弊（必须从发射线后弹、只能用一次发力）
- **地城嵌入**：每场战斗一个战斗盘，怪物位置随关卡变化 → 就是"关卡设计"

### 2. 落点 Drop ★☆
- **文具**：橡皮 / 笔帽 / 纸团
- **玩法**：从固定高度（如书上方 20cm）松手，落点决定结果。Dungeon Fighter"丢骰子砸靶"的文具版。
- **爽点**：抛物线不可控，紧张
- **技巧**：几乎没有 → **更像掷骰子**
- **结论**：**不推荐做核心**。适合做 Boss 的"命运一投"（一局一次的重大判定）
- **坑**：落地后反弹滚动会让结果争议大，需规定"第一次落点为准"

### 3. 滚动 Roll ★★
- **文具**：铅笔（**六棱柱 = 天然 d6**）/ 硬币
- **玩法**：滚铅笔过一条线，看停下时朝上的面，或停在哪个格子。
- **爽点**："铅笔居然能当骰子"——这个**发现感本身是卖点**
- **技巧**：控制力度让它停在目标区（有技巧，但受桌面摩擦影响大）
- **变体**：铅笔六面贴/写不同符号（玩家自己做 prep 也是一种仪式感）
- **坑**：铅笔太轻，滚动距离难控制；不同桌面摩擦差异大（可用"规定在书封面上滚"统一）

## 二、操控类（安静，适合办公室/教室摸鱼）

### 4. 擦除 Erase ★★
- **文具**：橡皮
- **玩法**：书页印一片灰色"涂层区"，玩家用橡皮擦。擦出来的图形/面积决定结果。例："30 秒内擦掉怪物，不许擦到旁边的宝箱"。
- **爽点**：像拆弹，稳不稳全看手。擦的动作本身解压。
- **技巧**：纯稳态控制，能练。
- **神来之笔**：**纸擦多了会破** —— 这可以变成机制：**纸的磨损 = 你的失误上限**（擦破即失败）
- **变体**：**擦到一半不能停**——必须一口气擦完，中途停手算失败（对抗犹豫）
- **坑**：橡皮消耗、橡皮屑（办公室友好度一般）

### 5. 一笔画 One Stroke ★☆
- **文具**：铅笔 / 圆珠笔
- **玩法**：一笔连续画线（不能抬笔），穿过尽可能多的目标，不能碰障碍。
- **爽点**：贪心——多穿一个还是见好就收
- **技巧**：路径规划 + 手稳
- **坑**：与"闭眼打靶"同属画线，**视觉上太像**，差异化不足。建议只在 Boss 用。

### 6. 连线 / 测量 Line & Measure ★★
- **文具**：**尺子**（每个学生都有）
- **玩法 A**：尺子对准两点画一条线，线穿过哪些格子决定结果（对准精度 = 技巧）
- **玩法 B**：用尺子量两点距离，**取毫米尾数**当随机数（如 73.5mm → 尾数 5）
- **爽点**：尺子 = 武器，有"几何感"和"工程师感"
- **技巧**：对准精度 / 控制长度
- **坑**：玩法 B 本质是掷骰子（尾数不可控），只能当辅助判定，不能做核心

## 三、结构类（用纸本身的物理性，设计感最强）

### 7. 叠加透光 Overlay ★★★ 强烈推荐
- **文具**：硫酸纸 / 描图纸（美术店几毛一张）/ 半透明便利贴
- **玩法**：册子里夹一张半透明页，上面印着"射线 / 网格 / 毒气 / 视野"。把它**叠在地图页上透过去看**——叠加产生的交点就是结果。
- **爽点**：**位置决定命运**。你移动/旋转透明页，就是在"瞄准"。这是空间层面的瞄准，比平面瞄准高级。
- **技巧**：空间想象 + 微调，上限高
- **为什么好**：
  - ① **完全不依赖印刷精度**（叠加关系容错大）
  - ② 视觉辨识度极高——"那本能透光的游戏书"，一句话就能记住
  - ③ 一个机制能长出无数变体：探照灯（找隐藏物）、毒气扩散（走位躲避）、视野遮挡（战争迷雾）、射线（连锁判定）
  - ④ 安静、优雅，适合"摸鱼"场景
- **坑**：要多印一叠透明页（成本 +几毛/本）；透明纸易皱（可用薄卡纸覆膜）

### 8. 折叠 Fold ★★
- **玩法**：把书页折一下，折痕 / 镜像决定结果。例："折过去，看怪物落在哪格"。
- **爽点**：不可逆的仪式感；"一折定生死"的决断感
- **技巧**：折叠精度（但主要是随机）
- **坑**：折多了书会烂（与"可重复玩"目标冲突）→ 建议只用于**一次性重大事件**（如最终选择）

### 9. 撕 / 剪 Tear ★★
- **玩法**：撕开一条封印，撕痕走向决定结果
- **爽点**：破坏欲 + 不可逆的紧张感，情绪强度最高
- **坑**：一次性的极致（撕完就没了）；纸屑不环保；与可重复玩冲突
- **结论**：不做核心，但**做 Boss 战的终局一击**极有戏剧性

## 四、消耗类（文具即资源，叙事感最强）

### 10. 铅笔即生命 Pencil = HP ★★★ 概念最好
- **玩法**：你的铅笔就是你的血量。每次受伤就**真的削一次铅笔**（或在铅笔上画一道刻度）。铅笔越削越短，短到握不住 = 游戏结束。
- **爽点**：**文具与游戏状态物理绑定**——这种实体隐喻极有记忆点
- **为什么是杀招**：它把"消耗品"从**缺点变成特色**。屁兜被骂"写完就废"，我们让"废"变成玩法本身。
- **坑**：真的削铅笔很麻烦（要卷笔刀、要清理木屑）
- **简化版**（推荐）：不改铅笔，在册子边缘印一条"铅笔刻度条"，受伤就涂掉一格，涂满 = 铅笔"用完"了。保留隐喻，去掉麻烦。

### 11. 墨水 / 橡皮即行动点 ★★
- **玩法**：笔芯墨水 = 行动点数；橡皮大小 = 治疗次数。用完就得换（一局游戏通常就是一支笔的量）
- **爽点**：资源管理 + 现实焦虑的戏仿（"笔没水了"是真实的办公室恐惧）
- **坑**：难以量化，只能做**叙事包装**不能做硬机制

## 五、我的推荐：三机制组合（一本书三种动作节奏）

单一机制玩 50 关一定会腻（屁兜第五章被骂"无聊"就是证据）。建议**一本书装三套动作**，节奏交替：

| 场景 | 机制 | 动作节奏 | 为什么 |
|---|---|---|---|
| **战斗** | **弹射**（笔帽撞怪 + 连击） | 动感、爽、能练、会笑 | 技巧上限最高，传播性最强 |
| **探索 / 解谜** | **透明页叠加** | 安静、烧脑、有辨识度 | 完全不怕印刷误差，视觉记忆点独一无二 |
| **资源管理** | **铅笔长度**（刻度条） | 叙事、压迫感 | 把"消耗品"这个行业通病变成我们的特色 |

**这套组合相对屁兜的优势**：
- 屁兜全程只有一个动作（画线 + 戳靶），第五章就腻了；我们有三种动作交替
- 屁兜怕印刷误差、怕手抖玩家；我们的判定全都容错大
- 屁兜"写完就废"是缺点；我们把"消耗"写成玩法

## 六、待验证（别急着动手做关卡）

新机制同样要过"手感验证"这一关。建议用**最低成本**先试：

1. **弹射**：A4 纸上画 10×8 格子，撒几个硬币当怪，用笔帽弹 20 次。
   - 记录：连击率、出界率、爽不爽、会不会太容易/太难
   - 关键指标：**第 20 发是否明显比第 1 发准**（技巧可练性）
2. **透明页叠加**：打印一张网格透明页，叠在地图上试 5 分钟
   - 关键指标：**有没有"啊，原来可以放这里"的顿悟**
3. **铅笔刻度**：先不管，等前两个定下来再考虑

**止损线不变**：如果弹射玩 20 发不觉得爽，或者练不出进步感，就换机制，**不要开始做关卡**。

## 七、法律备注

上述机制（弹射 / 叠加 / 擦除 / 滚动 / 消耗）均**不属于 PBA 或屁兜的表达层**：
- PBA 受保护的是：靶的图形美术、具体关卡布局与谜题、规则书文案、品牌名
- 弹射是 Crokinole（1876）就有的公共领域机制；叠加透光、擦除、滚动均为通用物理玩法
- **我们只要不照搬它们的靶面设计、关卡布局、文案，就不存在侵权风险**
