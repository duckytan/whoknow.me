## 零、先读这五条（其余可慢慢看）

1. **🔴 头号竞品《屁兜冒险》很可能不是国产原创，而是 Pocket Book Adventures（PBA）的未授权复刻。** 证据链完整但缺一纸声明（详见 §1.3）。这意味着：**中文市场至今没有本土原创的"闭眼打靶"地城桌游——空白是真的，而且比我们以为的更大。**

2. **品类正在增长，不是昙花一现。** PBA 的续作《Pencil Book Quest》2025-09 在 Gamefound 筹到 **$62,144 / 2,582 backers**（前作 PBA 2022 年 KS 是 $28,542 / 2,125 backers）。三年两作，backer 数增长 21%，金额增长 118%。这个赛道在被验证、在扩大。

3. **300 小时的成本账可以砍到 65–75 小时。** 用"逆向生成 + 求解器校验 + 六步流水线"，单关从约 6h 压到 1.5h。**这是本次调研最有价值的一条**——它把项目从"4-5 个月苦役"变成"两个月可交付"。

4. **全行业最大槽点高度一致：一次性消耗。** 屁兜评论原话"印刷质量不错，可惜纸质版是一次性的"；PBA 同样被骂。而**我们已有成熟解法**（哑膜覆膜 + 白板笔 / 活页靶页 / 补充装），这是吃掉对手最直接的刀。

5. **闭眼机制原作者自己都做了退路。** Grumpy Spider 在官方更新里主动放出 **"骰子替代判定系统"**，等于承认"闭眼瞄准并非人人适用"。**无障碍替代方案不是加分项，是必选项。**

### 1.2 章节口碑（玩家实玩长帖）

7 个区域各有独立移动规则：**草原（走1–4格撞障碍才转向）/ 荒野 / 森林 / 冰原（直线滑到撞停）/ 洞穴（闭眼点格最短路径走过去）/ 墓地 / 地城（任意方向不转弯，踩旧格跌层）**。

- **被夸最多**：第四章冰原（"像在解谜了，精心规划路线"）、最终章地城双层跌落、最终 Boss 多头蛇（"划了十几次后产生肌肉反应"）。
- **被骂最多**：第五章洞穴（"挺无聊的"——闭眼点格偏运气）、第六章 Boss（切割时反复擦边，损失武器）。
- **弃坑率**：【存疑】未见可信数据，摩点评论区无弃坑表述。

### 1.3 🔴 关键发现：屁兜冒险的真实身份

**判断：强证据指向"屁兜冒险 = PBA 的未授权复刻/换皮"，但无任何一方公开声明，故严谨表述为"未达 100% 确证"。**

| 证据 | 说明 | 可信度 |
|---|---|---|
| 时间线 | PBA **2022-10 KS，2023-06-28 发售**；屁兜摩点 **2023-08-06 才结束众筹** —— 立项时 PBA 已公开可购（itch $5 PDF） | 【确证】 |
| 结构雷同 | PBA = 50 标准关 + 7 Boss + 7 区域；屁兜 = 50–60 关 + 7 章节 + 7 Boss | 【确证】 |
| 机制逐字对应 | PBA："笔尖落攻击条圆点→闭眼→瞄向同心圆靶，阴影环触发怪物特殊能力，正中靶心 0 伤"；屁兜实测完全一致 | 【确证】 |
| 原厂无中文版 | Grumpy Spider 官网在售仅 3 款（PBA / Rucksack / Pencil Book Quest），**无中文版、无树豆合作、无"屁兜"字样** | 【确证】 |
| 摩点页无授权字样 | 以"树豆工作室"原创国货呈现，通篇无"引进/授权/原版" | 【确证】 |
| 排除"马甲"假设 | 树豆另有《神械密境》《黑色奏鸣曲》《果园》《烽火》《极恶西部》等独立原创线，与 Grumpy Spider 谱系无重合 | 【确证】 |

> **为什么这条对我们重要**：它说明这个机制在中文市场**只有"引进/复刻"覆盖过，从未有本土原创内容**。PBA 原作几乎无剧情，屁兜营销文甚至出现虚构背景——**"有扎实本土内容的原创中文版"这个位置是空的。**

### 1.4 该抄什么、该避什么

**抄**：
- 每章换一套移动规则（这是它最强资产，全网被夸的都是章节机制差异）
- **把怪物当解谜工具**——第 26 关"故意吃怪物技能才能停在宝箱格"是被反复引用的神来之笔；第 23 关"从净化药倒推路线"
- Boss 必须有一招"可练成、有肌肉记忆成就感"的手感动作（多头蛇斩首是口碑峰值）
- 宣发路径：短视频演示"一本册子+一支笔"，小红书/抖音破圈已被验证

**避**：
- 一次性消耗（最大槽点）
- 闭眼点远端格无容错（第五章被判"无聊"的真正原因是容错为零）
- "非惯用手强制瞄准"这类无谓门槛
- 中段机制新鲜度不足（第五章连推闭眼关导致疲态）
- 印刷品控（屁兜第 5 页图标漏印，官方补发贴纸）

## 二、源头产品：Pocket Book Adventures（PBA）

### 2.1 商业数据

| 项 | PBA（2022-10 KS） | Pencil Book Quest（2025-09，续作） |
|---|---|---|
| 平台 | Kickstarter | Gamefound |
| 筹款 | **$28,542**（目标 $2,800，1019%） | **$62,144** |
| Backers | **2,125** | **2,582** |
| 均价 | $12（实体，含美境内运费） | — |
| 现价 | 官网 $5（PDF）/ $12（实体） | — |
| 体量 | 50 关 + 7 Boss，7 区域，每关 2 页 | 80 关，分支任务，boss 守护道具 |

**信号**：三年内同一个设计师（David David / Grumpy Spider Games）连出两作，金额翻 1.2 倍、backer 涨 21%。**品类在被持续验证，不是一次性热潮。**

### 2.2 规则细节（值得逐条对照）

- **攻击条**：怪物图标上方一条带圆点的线；笔尖落圆点 → 闭眼抬起 → 落向下方靶心
- **靶构造**：同心圆 + 环带，部分环带**阴影**；**正中 = 0 伤且击杀**；越外环伤越重；**落阴影区 = 触发该怪特殊能力**（需 Remedy 解除）
- **存档**：纯书内标记（HP/金币/道具记在书上，关间回城镇，合上书即存盘）
- **道具体系**：Remedy（解状态）、Pixie Dust（回血）、Expand-O-Gravel（**造墙**）
- **Boss 变体**：Molterra（岩浆每回合上涨、限时逃生）、多头蛇（画线砍头，脱靶全头重生并反伤）、恐慌网格移动

> 注意"**Expand-O-Gravel 造墙**"这个道具——我们第一章第 4 关的"自己造个刹车"也用了造墙。这说明它是这类机制的通用解，不算抄，但要注意表达方式必须独立。

### 2.3 玩家抱怨（三条，与屁兜完全一致）

1. **闭眼戳不准**：页面小、靶小，实战难瞄，规划好的路线被打乱
2. **无障碍差**：手抖/视力差者几乎玩不了，评测者明确呼吁提供替代方案
3. **一次性消耗**：原版实体划过即废，只能靠重新打印 PDF 解决

**关键信号**：Grumpy Spider 在官方更新 #4 放出 **"alternate die-based resolution system"（骰子替代判定）**——**原作者自己承认闭眼瞄准不是人人适用。**

## 三、机制谱系与设计规律

### 3.1 谱系图

```
1876 ── Crokinole（木盘同心圆，弹射木片入环）★投射靶始祖
1995 ── PitchCar（弹射赛车，纯出界判定）
2010 ── Catacombs（弹射棋子打怪，二值命中）
2011 ── Dungeon Fighter（★核心节点：掷骰砸数字靶，须先弹桌一次
                          + 闭眼/反手/胯下等怪姿势）
2015 ── Flick 'em Up（弹射子弹，3D 遮挡分区）

── 分支 A：笔 + 盲画（纸面靶支线）──
~2010s ─ Doodle Doo（蒙眼用笔走迷宫）★纸笔闭眼祖先
2022 ─── Pocket Book Adventures（铅笔 + 闭眼 + 同心圆靶 + 7 区域）
2023 ─── 屁兜冒险（PBA 中文复刻）
2025 ─── Pencil Book Quest（80 关续作）
                    ↓
              【胡闹冒险】← 我们在这
```

**关键跳变**：Dungeon Fighter 把"闭眼 + 分区靶"做成核心循环；PBA 把投射物从骰子换成笔、把靶从立体盘压成书页。**我们站在这条支线末端，且是中文原创的第一个。**

### 3.2 已被数学验证的命中规律

- **命中概率 = 环面积比**（严格正比）。例：外径 20"、内圈直径 5/10/15" 的靶，概率分别 6.25% / 18.75% / 31.25% / 43.75%【确证】
- 真实弹道更接近 **Rayleigh 分布**（水平/垂直独立高斯 → 半径分布），比朴素面积比更贴近"高手集中、新手外扩"【确证】
- **惩罚区放中圈，不要放最外圈**。最外圈应是"最易命中的安全低伤区"以维持正反馈；靶心放"完美闪避/暴击"制造高光【单一 + 设计共识】

### 3.3 可执行参数建议

| 参数 | 建议值 | 理由 |
|---|---|---|
| 攻击条→靶距 | **8–12 cm** | 太远闭眼失控，太近无张力。（我们当前 32mm 偏短，试玩时建议对照测试 60/90/120mm 三档） |
| 靶径（外圈） | **4–6 cm** | 参考 Crokinole 的 20:1 比例缩放；太大难度崩，太小手残劝退 |
| 分区数 | **3 圈 + 靶心** | 超过 5 圈在闭眼下肉眼无意义（Dungeon Fighter 的 1–10 数字环是睁眼设计） |
| 面积占比 | 外圈 45% / 中圈 35% / 内圈 15% / 靶心 5% | 使"3–4 次命中可杀普通怪" |
| 惩罚区 | 做**环带**放中圈，最外圈留安全低伤区 | 维持正反馈 |
| 闭眼分级 | 常规怪睁眼 / Boss 与特殊武器闭眼 | 保技巧上限，给新手缓冲 |
| 笔纸 | 圆珠笔 0.5mm 或铅笔 + **未涂布道林纸** | 铜版纸太滑线会飘，糙纸太涩笔尖卡 |

> ⚠️ **与我们现有设计冲突一处**：README 里锁死"攻击条距靶心 32mm"，国际建议是 80–120mm。**这是我目前发现的唯一硬冲突，建议试玩阶段用练习靶做三档对照（32 / 70 / 110mm），用数据定，不要拍脑袋。**

### 3.4 已知坑

- **可访问性通病**：dexterity 元素天然排斥残障玩家，且策略派与动作派受众互斥【确证】——必须提供替代判定
- **Dungeon Fighter**："即使简单难度也极难"，新手连败劝退【单一】
- **Catacombs**：无护栏，强力弹射常飞出盘面 → 落点争议、战术重复【确证】
- **技巧上限是双刃剑**：熟练者与新手差距显著，会劝退新手【确证】

### 4.3 存档问题的四种解法

1. **战役式角色表**（D100 / 4AD / 2D6）：跨局成长，多次短局拼成长期冒险
2. **书内存档格**（PBA）：最适合通勤碎片化
3. **可擦写/活页/分册**：2D6 有精装可擦版
4. **重开即新故事**（日记式 RPG）：靠"不可重复的情绪"驱动复玩

### 4.4 定位启示

**"闭眼打靶"在单人纸笔地城里是稀缺卖点。** 检索到极少数先例——PBA、Blind Luck（闭眼画圈当骰子）、Blind Blade、Dungeon Pen——**全都小众，无一成为主流**。主流是"读表+写作"型。

**差异化该押在哪**：
1. 把"闭眼打靶"做成不可替代的**手感护城河**（国际竞品几乎没有的感官维度）
2. **不要硬拼"日记沉浸"**（TYOV / Apothecaria 的领地）；我们该主打**快节奏、高密度决策、零画工门槛**——正好补 Delve"手绘门槛"的短板
3. **借尸还魂"存档/可擦写"**：可擦写攻击条 + 分册进度卡，解决纸笔一次性痛点
4. **渠道**：itch.io（PWYW 引流）+ DriveThruRPG（付费 PDF）+ 众筹（$10–15 档）

**一句话**：国际市场上"闭眼打靶"不是红海，是蓝海。押"感官化决策 + 可重复实物 + 轻量决策密度"，避开与日记式沉浸正面竞争。

## 五、关卡设计方法论（★ 成本压缩的关键）

### 5.1 三条已被验证的方法

1. **逆向设计法**：先写"本关啊哈点 = ______"，再围绕它摆障碍。不要先画图再碰运气【确证】
2. **一关一机制**：每章只引入 1 个移动规则变量，关与关之间只加 1 个新约束。Stephen's Sausage Roll 全程只有三件套、86 关不换核心机制，却每关给新顿悟
3. **锯齿难度曲线**：引入→练习→变奏→综合→精通，新机制到来时难度地板回落再升。**不要直线上涨**

### 5.2 每章 7 关的推荐配比

| 关位 | 职责 | 做法 |
|---|---|---|
| 1 | 教学关 | 最空旷地图，只让玩家体会新规则 |
| 2–3 | 变奏关 | 加 1 个锚点或 1 面墙，制造第一次顿悟 |
| 4–5 | 综合关 | 移动谜题 + 战斗机制叠加 |
| 6 | 反转关 | 打破刚建立的假设（如"锚点总安全"→某锚点被怪占） |
| 7 | Boss/峰值关 | 本机制最难一题，**之后必须给一关喘息关** |

**疲劳点**：Bloxorz 第 7 关是公认第一个高峰；Snakebird 玩家普遍在第 20 关前后弃游。**每章第 7 关是疲劳高发点，下一章开头必须降复杂度。**

### 5.3 滑行谜题的构造规律（直接适用冰原章）

- **核心规律**：冰滑 = "只有墙/怪/锚点能停"。**锚点（石块/冰面踏板/怪）作为转向站**是关键套路
- **可解性分级**（Tommy Odland）：
  - 弱可解：终点可达，但走错会卡死循环
  - **强可解：无论如何不会卡死**
  - **可逆：能从终点滑回起点**
  - → **我们的关卡至少要做到"可解 + 可逆"**（纸笔游戏无法撤销滑动路径时尤其致命）
- **三类死锁必须扫描**：角锁（两堵垂直墙夹角）、边锁（贴边界且该行列无目标）、冻结锁（被墙+死格夹死）

### 5.4 手工 vs 生成：50 关该怎么做

**结论：生成器 + 人工筛选混合最划算，且质量有学术背书。**

- de Kegel 2020 综述：程序生成的 Sokoban 关卡，玩家投入度与**手工关无显著差异**
- **逆向生成法**（从已解状态反向滑动得到起点）保证可解，是 Sokoban 标准做法
- Zachtronics（Zach Barth）实战：手工写"关卡设计表"批量出概念 → 试玩筛选淘汰无聊关。他强调"**人眼判断可解性不可靠，必须机器校验**"

→ **把"从零画 50 关"变成"从候选池挑 50 关 + 微调"，单关从 6h 压到 1.5–2h。**

### 5.5 ★ 造关流水线（空白页 → 定稿约 75–90 分钟）

| 步骤 | 动作 | 耗时 | 自检 |
|---|---|---|---|
| 1 定洞见 | 写"本关啊哈点=__"，确认只含 1 个新约束 | 10 min | 一句话能说清？含 >1 新变量则拆关 |
| 2 逆向布图 | 先摆终点/靶心+攻击格，反向滑出起点；放 1–2 锚点 | 20 min | 起点≠终点，路径非空 |
| 3 死锁扫描 | 查角锁/边锁/冻结；确认可解+可逆 | 10 min | 无边界孤格、无死角目标 |
| 4 设计者盲解 | 不看笔记重解，计时 T₀，记卡点 | 15 min | T₀ 在 3–8 分钟 |
| 5 找 1 人盲解 | 记录其卡点与用时 | 20 min | 有卡点 = 步骤 6 补锚点 |
| 6 校准定稿 | 调墙/锚点/距离；过易撤停靠点，过难加停靠点 | 15 min | 盲解用时在 1.5×–3×T₀ 之间，0 人卡死 |

**质量三道闸**：① 机器可解性（必须过）② 啊哈点存在（步骤 1 留痕）③ 盲解阈值（步骤 5–6）。三闸全过才进下一关，**避免"画完 50 关发现第 30 关无解"的返工灾难**。

**章级提速**：每章先做第 1 关模板定型，第 2–7 关用"改 1 变量"派生（步骤 2–3 可半自动），只对第 6、7 关投入完整人工雕琢。

> **成本核算**：50 关 × 约 80 分钟 ≈ **65–75 小时**（原估 300 小时的关卡设计+校准部分）。省下的时间应投入 Boss 设计与试玩。

## 六、制作工艺与成本

### 6.1 打印精度（命门）

**最大陷阱**：PDF/浏览器默认"适应页面"会把满版 A4 缩到 **94%–97%**（打印机 4–5mm 不可印边距所致），靶心面积比直接失真。

**保证 100% 实际尺寸的做法**：
- 文件端：矢量 PDF，锁 210×297mm，留 3mm 出血，**首页画 100mm 校准方框**
- 设置端：选「实际大小 Actual Size」（非"适合"）；关闭无边框/照片增强；纸张手动设 A4；**绝不用手机打印**（iOS/安卓无条件 fit-to-page）
- **验证**：每次先打校准页，用钢尺量 100mm 方框，**误差 >0.5mm 即重设**

### 6.2 纸张（摩擦系数比美观重要）

| 纸种 | 闭眼划线手感 | 适用 |
|---|---|---|
| 铜版纸（亮面） | ❌ 太滑，笔迹难干易糊 | 封面，不用于内页 |
| 哑粉纸 | 尚可，仍偏滑 | 彩图内页 |
| **双胶/道林纸 100–120g** | ✅ **有"纸齿"阻力，闭眼控线最好** | **内页首选** |
| 白卡 200–350g | 偏硬 | 封面 / 单独靶卡 |

### 6.3 可重复书写（解决最大槽点）

- **覆膜用哑膜，不用亮膜**：亮膜太滑，白板笔墨水会聚成水珠擦不净；**哑膜干擦数百次不残留**【确证】
- **笔首选白板笔**：哑膜上干擦干净，可擦 200–1000 次。**百乐 FriXion 在覆膜上打滑、显色淡、低温会"复活"字迹，不作覆膜靶页主笔**
- 其他方案：塑封机（¥100–200）+ 哑膜袋（¥0.3–0.8/张）；**活页/可替换靶页**（磨损后换页，最实用）

### 6.4 装订（必须能摊平）

| 方式 | 摊平 | 成本系数 | 建议 |
|---|---|---|---|
| **骑马钉**（8–64 页） | ✅ 180° 全平 | ×1.0 | ✅ 32 页内页首选，最便宜 |
| 胶装 | ❌ 仅 170° | ×1.26 | ❌ 摊不平，书上划线难受 |
| **线圈/活页** | ✅ 360° 翻 | 中 | ✅ 可换靶页，解决消耗痛点 |

### 6.5 小批量成本（2026-09 行情）

| 数量 | 骑马钉 A4 彩印单价 |
|---|---|
| 100 本 | 约 8–12 元/本 |
| 500 本 | 约 4–7 元/本 |
| 打样 | 10–50 元/本，1–3 天 |

桌游定制厂商 MOQ 通常 **500 套起**（东莞港通、宏盛、宁波朝阳等）。

### 6.6 两阶段方案

**① 试玩阶段（¥20–40 撑过 5 关）**
80g 道林纸 + 家用打印（100% 实际大小，先打校准页）+ 只塑封靶页 + 白板笔 + 订书机骑马钉。

**② 量产阶段（推荐组合）**
100–120g 双胶纸内页 + **靶页单独抽印哑膜覆膜（+0.3–0.5 元/本）** + 200–250g 铜版封面哑膜 + 骑马钉（或线圈活页）。给工厂矢量 PDF 并书面要求"100% 实际尺寸、禁止适应页面"，**打样先验**（游标卡尺量靶心偏移）。

## 七、发行与商业路径

### 7.1 众筹平台（关键事实：个人可以上）

| 平台 | 个人能否发起 | 抽成 | 备注 |
|---|---|---|---|
| **摩点** | ✅ **可以**（年满 18 + 身份证 + 大陆银行卡，**无需营业执照**） | 当前 **0% 服务费 + 1% 支付费** | 筹款期建议 ≤60 天；分三笔结算（50%/30%/尾款）；发货后 90 天内他渠道售价不得低于众筹价 |
| 新物集 | ✅ 可以（需符合《电商法》豁免之一） | 1%–3%【单一】 | 桌游垂直，有宣发补贴 ≤¥3500 + 试玩网络 |

### 7.2 售卖渠道与"无执照"影响

**法律底线**：《电商法》第十条原则上需登记，但豁免"零星小额（年累计 ≤10 万元）"等四类。**即无执照可卖，但有年 10 万天花板**【确证】。

- **淘宝个人店**：身份证+人脸即可，保证金 500 元起（可退），佣金 0.5%–5%【确证】
- **抖音小店**：个人门槛高；**"图书/出版物"类目强制营业执照**——一本册子可能被归入此类【单一，需实测】
- **最轻量合规方案**：**注册个体工商户，全国注册费 0 元**，凭电商平台"网络经营场所证明"即可（无需实体店面），1–3 工作日办结，月销 ≤10 万免征增值税【确证】

### 7.3 海外渠道（关键事实：Kickstarter 大陆个人不能直接上）

- **🔴 Kickstarter 支持国家列表不含中国大陆**（支付商 Stripe 地域限制）【确证】。变通路径只有一条：在受支持地区注册实体（美国 via Stripe Atlas / 中国香港 / 新加坡）。已验证的大陆案例均走此路（如《疯狂深渊》注册美国公司 Diemension Games）。
- **itch.io 对中国个人完全开放**：无需执照，支持 PWYW，平台抽成由创作者自定 0%–10%，**已支持 Payoneer 提现直接落国内银行卡**【确证】。这是最友好的出海口。
- DriveThruRPG（数字 PDF）、The Game Crafter（POD 实体代发，设计师留 70%）作为补充。

### 7.4 消耗品的商业应对（已被验证的模型）

1. **可擦写版卖高价**（Railroad Ink 用可擦写板；Speed Colors 配干擦卡并出扩展）
2. **卖补充装靶页**（对我们最贴：主体册子反复用，靶页低价复购）
3. **续作分册**（PBA 已走这条路：Pencil Book Quest）
4. **电子版低价 + 实体高价**（PDF 自印获客，精装收溢价）

### 7.5 定价建议

对标：屁兜 45–68 元（已立锚点）、谜宫 129 元（重工艺收藏向）、K的游戏 27 元起、PBA $12。成本 8–12 元/本（100 本）。

| 档位 | 建议价 |
|---|---|
| 标准版（册子+笔） | **49 元** |
| 早鸟/众筹档 | **39 元**（低于零售约 20%） |
| 豪华版（可擦写板+专用笔） | 79–89 元 |
| 补充装靶页包（50 张） | **9.9 元** |
| 电子版 itch.io | $3–5 或 PWYW |

### 7.6 分阶段路径（前期现金投入 ≤¥2,000）

| 阶段 | 动作 | 花费 |

| **0 验证期** | PDF 自印 → 小红书/桌游吧招募 30–50 人试玩；同步挂 itch.io PWYW 测海外兴趣 | ¥300–500 |

## 八、版权边界（必须遵守）

### 8.1 法律判断

| 层级 | 是否受保护 | 我们的做法 |
|---|---|---|
| **机制/规则**（闭眼用笔瞄准同心圆靶决定伤害） | ❌ 通常不受著作权保护（保护"表达"不保护"思想"） | ✅ **可复用** |
| **靶的图形美术** | ✅ 受保护 | ❌ 必须独立绘制 |
| **具体关卡布局与谜题** | ✅ 受保护 | ❌ 必须独立设计 |
| **规则书文案** | ✅ 受保护 | ❌ 必须自己写 |
| **品牌名**（Pocket Book Adventures / 屁兜冒险） | ✅ 受保护 | ❌ 不得使用 |

**额外风险**：中国《反不正当竞争法》下，若与屁兜/PBA 高度相似致市场混淆，可能被诉"仿冒/搭便车"。但屁兜本身疑似未授权复刻、源头 PBA 在华举证成本高，**实际被诉概率中等偏低**。

**安全边界**：抄"机制"相对安全；照搬"靶面阴影分区→能力映射"、具体 7 区域移动规则、具体地图、怪物立绘、书名 → **高风险**。

> ⚠️ 以上为调研结论，**不构成法律意见**。若进入量产售卖，建议咨询知识产权律师。

### 8.2 差异化空间（本土原创 vs 引进/复刻）

| 对手短板 | 我们的机会 |
|---|---|
| 一次性消耗本 | 可擦写 + 活页靶页 + 补充装 |
| 靶小难瞄、无容错 | 放大靶面 + 分区简化 + 容错设计 |
| 无障碍差 | **提供替代判定**（原作者官方都做了，这是标配） |
| 原作几乎无剧情 | **扎实本土中文叙事**（胡闹宇宙的资产正是梗和叙事） |
| 纯单人 | 可考虑合作/对战、元进度、App 辅助计分 |
| 定价 45–68 元 | 性价比切入或精品化错位 |

## 九、结论与待拍板决策

### 9.1 调研结论

**支持继续做。** 三条理由：
1. **市场被验证且在增长**：屁兜千盒级 + 京东 1000+ 评论；PBA 两作共筹 $90k+ / 4,700 backers，续作金额翻倍。
2. **中文本土原创是真空**：现有中文产品是引进/复刻，无本土内容。
3. **成本账大幅改善**：300h → 约 75–100h（关卡部分 65–75h），最大瓶颈被方法论破解。

但**手感验证仍然是第一关**——不爽则一切归零，这一点没变。

### 9.2 需要你拍板的五件事

| # | 决策 | 选项 | 我的建议 |
|---|---|---|---|
| 1 | **攻击条距离** | 维持 32mm / 改 70mm / 改 110mm | 试玩阶段做**三档对照**再定，别拍脑袋。国际建议 80–120mm 与我们现设计冲突 |
| 2 | **可重复方案** | 覆膜 / 活页靶页 / 补充装 / 不管（学屁兜一次） | **做成核心卖点**。哑膜 + 白板笔 + 可换靶页，直接打对手最大软肋 |
| 3 | **无障碍替代判定** | 做 / 不做 | **必须做**。原作者官方都放了骰子替代，这是标配不是加分 |
| 4 | **内容量目标** | 50 关 7 章 / 缩到 25 关 4 章 / 先 5 关 | 试玩后定。若手感成立，建议**先做 25 关 4 章**（约 40h），比 50 关早半年上市 |
| 5 | **商业路径** | 纯自用 / itch.io PWYW / 摩点众筹 / 淘宝店 | 按 §7.6 四阶段走，前期 ¥2,000 内可启动 |

### 9.3 下一步（不变）

**打印 → 练习靶 D 连打 20 发 → 玩完 5 关 → 填试玩记录表。** 但**增加一项**：练习靶增加**三档攻击条距离对照**（32 / 70 / 110mm），每档打 10 发，记录命中分布与主观爽度——用数据回答决策 #1。
