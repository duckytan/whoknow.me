## 3. 现场脚本（逐字念，不许自由发挥）

### 3.1 邀人话术（微信转发即可）

> 「帮个忙试个东西，二三十分钟，正常点单玩一遍就行，完了请喝奶茶。手机上加个主屏就能用，纯玩别多想。」

### 3.2 开场白（逐字念，一人一次）

> 「帮个忙试个东西。就当在点外卖，想点啥点啥。规则不解释，有问题问了也不答，最后再一起聊。」

念完闭嘴。**不许说**「这是个游戏」「这是假的」「注意看老板说什么」「等下有个彩蛋」。

### 3.3 三句引导语（只给选项名，不给任何理由）

| 时机 | 逐字念 |
|---|---|
| 第 2 单前 | 「这单地址选**公厕**，备注选**多放辣**。」 |
| 第 3 单前 | 「再来一单，跟刚才**一样的**就行。」 |
| 第 6 单前 | 「再点一单，还是**公厕**，备注这次选**表演才艺**。」 |

卡住超过 15 秒只说一句：「随便点。」其余一律不指路。第 1、5 单自由选，全程不干预。

### 3.4 闭场两问（顺序不许改）

- **Q1（开放锚定，不提示任何选项）**：「刚才哪一下最好笑？」
- **Q2（反事实，本轮核心）**：「如果这些话不是出现在这个界面里，而是直接微信发给用户，还好笑吗？」—— 答「那就没意思了」= 外壳有放大作用；答「一样好笑」= 段子独立成立。

选问（Q1/Q2 之后有空才问）：「会截图发给谁？」「有没有哪一下觉得假？」
**全程不主动问**「选的备注有没有反应」——这句会直接毁掉 §6 的专项观察。

### 3.5 主持人红线（犯一条则该人数据作废）

不笑 · 不解释梗 · 不指路 · 不剧透 · 无旁人出声 · 被问「这什么意思」只答「觉得呢」。

### 5.2 主判据（B 口径 · 8 人 × 6 单 = 48 单 = 336 节点观察）

| 门 | 指标 | 过门 | 不过门 |
|---|---|---|---|
| **1 笑率** | LR 总体笑率（≥L2 节点 ÷ 336） | **≥35%** | <25% |
| | NER 非空单率（至少 1 个 L2 的单 ÷ 48） | **≥90%** | <75% |
| | SR 强反应率（L3/L4 节点 ÷ 336） | **≥12%** | <7% |
| | L4C 截图冲动（8 人各自次数的**中位**） | **≥3 次** | ≤1 次 |
| | TTF 首爆点（8 人第 1 单的**中位**） | **≤3.0 秒** | >6.0 秒 |
| **2 密度** | GD 平均爆点密度（≥L1 节点占比的均值） | **≥0.57** | <0.43 |
| | 冷场次数（连续 ≥3 节点全 L0） | **≤2 次** | >5 次 |
| **3 疲劳** | RF-A 同组合衰减（第3单 vs 第2单 ≥L1 格数） | **≤70%** | >90% |
| | RF-A **察觉重复人数** | **≤2 人** | **≥3 人直接不过门** |
| | RF-B 换组合衰减（第4单 GD vs 第2单 GD） | **≤25%** | >45% |
| | RF-C 复玩欲（第5单 试新+1 / 重复 0 / 「够了吧」−1，8 人合计） | **≥3 分** | <0 分 |

**综合**：三门全过 → **PASS**；任一门不过门 → **FAIL**；其余 → **CONCERNS**。

### 5.3 算例（8 人 × 6 单 = 48 单，照格式套）

**门1**：LR = 121÷336 = **36.0%** ≥35 → 过 ｜ NER = 44÷48 = **91.7%** ≥90 → 过 ｜ SR = 45÷336 = **13.4%** ≥12 → 过 ｜ L4C：8 人次数 4,3,5,2,3,4,3,4 → 排序 2,3,3,3,4,4,4,5 → 取**第 4、5 位** → (3+4)÷2 = **3.5** ≥3 → 过 ｜ TTF：2.1,1.8,3.4,2.6,1.2,4.1,2.9,3.8 → 第 4、5 位 → (2.6+2.9)÷2 = **2.75 秒** ≤3.0 → 过 → **门1 过门**
**门2**：GD 均值 0.61 ≥0.57 → 过；冷场 2 次 ≤2 → 过；TTF 同上门1 → 过 → **门2 过门**
**门3**：RF-A 均值 62% ≤70 可接受；察觉重复 **2 人** <3（硬失败条款未触发）；RF-B 均值 22% ≤25 → 过；RF-C 合计 +5 ≥3 → 过 → **门3 过门**
**→ 综合 = 三门全过 = PASS。**
**兼容轨（非判据）**：48 单分数分布 1分×2、2分×6、3分×8、4分×20、5分×12 → 取**第 24、25 位**，两位都落在 4 分 → **中位 4.0** ≥3.5 ✅；≥4 分 = (20+12)÷48 = **66.7%** ≥60% ✅ → A 口径下同判 PASS。
> 中位数算法：N 为偶数取**排序后第 N/2 与 N/2+1 位的均值**（8 人 → 第 4、5 位；48 单 → 第 24、25 位）。
