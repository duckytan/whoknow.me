## 🚦 红绿灯分级

### 🟢 绿灯（自由生成 · LLM 无需过滤）

- 天气、节日、食物
- 日常生活段子
- 抽象情感（喜怒哀乐）
- 老板人设（暴躁 / 佛系 / 怪异 / 懒散 / 哲学）
- 虚构 NPC（老王 / 张阿姨 / 小黑等）
- 玩家互动（"你" / "宝贝" / "亲"在合适人设下）

### 🟡 黄灯（关键词过滤 · LLM 生成后 + 自动过滤）

#### 竞品品牌（D1 拍板：不允许出现，用代名词）

**禁用品牌名**（必须替换）：
- 美团 / 饿了么 / 淘宝 / 天猫 / 京东 / 拼多多 / 抖音 / 快手 / 小红书
- 其他外卖 / 电商 / 内容平台

**代名词方案**：
- 美团 → "某外卖平台" / "某团" / "某外"
- 饿了么 → "某外卖" / "某饿"
- 电商 → "某宝" / "某猫"

#### 真实人名（D2 拍板：现代人一律化名，古代人可提）

**古代人**（可提，化名优先）：
- 孔子、老子、孟子、庄子、诗仙（李白）、诗圣（杜甫）
- 其他历史人物可酌情

**现代人**（必须化名）：
- 真实明星 / 网红 / 政治家 / 商人
- 用代称："某明星" / "某网红" / "某总"

#### 节日（D3 拍板：全都要，国内外的都要）

**国内传统节日**（自由提）：
- 春节 / 元宵 / 清明 / 端午 / 中秋 / 重阳 / 腊八

**国内现代节日**（自由提）：
- 国庆 / 劳动节 / 青年节 / 妇女节 / 双十一 / 双十二 / 618

**国外节日**（自由提）：
- 圣诞 / 感恩节 / 万圣节 / 情人节 / 复活节

**节气**（自由提）：
- 立春 / 雨水 / 惊蛰 / 春分 / 清明 / 谷雨 / 立夏 / 大暑 / 处暑 / 白露 / 秋分 / 寒露 / 立冬 / 小雪 / 大雪 / 冬至 / 小寒 / 大寒

#### 文化擦边

- 真实地名 → 化名（"京城" / "临安" / "魔都" / "帝都"）
- 真实医院 / 学校 / 公司 → 化名

### 🔴 红灯（绝对禁止 · LLM 生成后 + 人工审核必看）

#### 政治敏感

- 任何国家领导人姓名（现任 / 历任）
- 政治事件（涉及敏感历史）
- 宗教争议
- 民族 / 地域歧视用语
- 邪教组织名称

#### 色情 / 暴力

- 性器官 / 性行为露骨描述
- 杀人 / 自杀 / 暴力过程描述
- 校园霸凌 / 职场霸凌
- 自残 / 自杀暗示

#### 歧视

- 性别歧视（"女司机"等）
- 地域歧视（"某省人都..."）
- 职业歧视（"程序员都秃"等）
- 民族 / 宗教歧视

#### 威胁 / 违法

- 暴力威胁（"我知道你住哪" ← **waimai 现有话术，必须改**）
- 跟踪 / 骚扰暗示
- 教唆犯罪
- 盗版 / 侵权
- 毒品 / 赌博

#### 真实信息（除 D2 古代人外）

- 真实人名（现代明星 / 网红 / 政治家）
- 真实公司名（除非已授权）
- 真实地址 / 电话 / 身份证
- 真实医疗机构 / 药品
- 真实车牌 / 银行账号

#### 虚假宣传

- 暗示真实外卖
- 暗示真实商家（"联系老板退钱"等）
- 暗示真实优惠（"满 100 减 50"等具体金额）
- 暗示真实食品安全

## 🔐 虚构交易闸门（fiction_paywall）· v1.1 新增

> **来源**：三司会审 2026-07-28 裁定——`fiction_flag`（本次消费虚构）不能只是策划自填标签，必须做成**机器可校验的硬规则**。
> **定位**：本闸门是「虚假宣传·暗示真实外卖/商家/优惠」红灯的**精度强化层**，专打"诱导玩家做真实付款/转账"的语义，**0 容忍**。
> **扫描点**：NPC 戏精台词、DRAMA 分支链 `text`、系统提示、评价模板——凡是会进 waimai/mart 前端的文本都要过。
> **联动**：命中即 `forbidden_check.fiction_paywall.triggered=true`，整条配置**拒绝落盘（或降级到 fallback）**，绝不进前端。字段形状见 `api-spec.md` §JSON Schema；扫描函数代码见 `docs/FICTION-PAYWALL-SPEC.md`（提案，未落 `engine/`）。

### 🔴 红灯词（真实交易诱导 · 0 容忍 · 一律拦截）

> 匹配即拦截（中文 + 英文变体）。中文长词排前，避免"支付"抢先匹配"微信支付"。

| # | 红灯词 | 变体 / 英文 | 为何拦截 |
|---|--------|-----------|---------|
| 1 | 付款 / 支付 | pay / payment | 直接要求玩家付钱 |
| 2 | 微信支付 / 支付宝 | Alipay / WeChat Pay | 点名真实支付渠道 |
| 3 | 扫码付 / 扫码付款 | scan to pay | 诱导扫真实收款码 |
| 4 | 微信扫 / 扫一扫付款 | scan QR to pay | 同上，弱组合捕获 |
| 5 | 转账 / 转给我 | transfer (money) | 要求真实转账 |
| 6 | 私聊转账 / 加微信转账 | DM transfer | 绕过平台私下收款 |
| 7 | 到付 / 货到付款 | COD / cash on delivery | 真实物流收款 |
| 8 | 下单立减 | order discount | 暗示真实下单优惠 |
| 9 | 实付 / 实付金额 | actual paid | 真实金额结算 |
| 10 | 银行卡 / 银行卡号 | bank card | 索要/引导真实卡信息 |
| 11 | 信用卡 / 花呗 | credit card | 真实信贷/支付 |
| 12 | 充值 / 充值余额 | top up / recharge | 真实账户充值 |
| 13 | 付款码 / 收款码 | payment QR | 真实收款码 |
| 14 | 打钱 / 汇款 | send money | 真实汇款 |
| 15 | 微信红包 / 发红包 | red packet | 真实金钱红包 |
| 16 | 现金支付 / 现金结账 | pay in cash | 真实现金交易 |
| 17 | 收银台 / 结账台 | checkout / pay now | 真实结算入口 |
| 18 | 余额（真实账户语境） | balance | 真实账户余额（配白名单豁免） |

### 🟢 白名单 / 放行（误杀防护 · 虚构梗必须过）

> 这些"交易词"出现在戏精台词里是**虚构表演**，不算真实诱导，命中红灯词时**豁免**。

| 放行词 | 典型用法 | 为何不算真实诱导 |
|--------|---------|----------------|
| 免单 | "今天你手气好，这单免单！" | NPC 虚构请客，无真实收款 |
| 这单我请 | "别争了，这单我请" | 虚构慷慨，钱不走真实通道 |
| 假装付款 | "别真掏钱，假装付款演给我看" | 显式声明虚构 |
| 虚拟币 / 游戏币 | "用你 999 游戏币结账" | 明确游戏内货币 |
| 赊账笑话 / 挂账 | "先挂账，下辈子再还" | 玩笑梗，无真实债务 |
| 脑内付款 / 意念结账 | "脑内已扣款，谢谢惠顾" | 荒诞内核台词 |
| 模拟下单 | "模拟下单成功，演技 +10" | 声明模拟 |
| 白嫖 | "这波白嫖老板笑开花" | 网络梗，无真实金钱 |

> **豁免逻辑**：先扫红灯词 → 命中后查上下文（前后 4 字是否含`假装/虚拟/游戏/脑内/意念/模拟/演/请/免单/赊/白嫖/挂账`等标记）→ 命中豁免则放行。第 18 条 `余额` 仅在无上述虚构标记、且上下文为真实钱包/账户时拦截。

## 🎚️ 智能审核的"误杀率"（D6 拍板）

### 早期（M0-M2）

| 等级 | 比例 | 含义 |
|------|:----:|------|
| 错杀率 | 10% | AI 拒绝生成的话术有 10% 其实可以发 |
| 漏掉率 | 0.1% | AI 放过的红线有 0.1% 应该被拦 |

### 玩家多了之后（M3+）

收紧策略：
- 错杀率降到 5%
- 漏掉率保持 0.1%（不放松）
