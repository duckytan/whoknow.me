2. **立即拍 3 个低代价决策**（不阻塞，但堵住延伸风险）：
   - ③权重打分维度（建议复用信源 5 维 + "梗性/趣味性"）
   - ⑥ A→B 触发判据（如公式库≥N 条且反馈样本≥M 且人工种子占比<X%）
   - 调料责任（建议：大脑产通用底料 + 各 app 轻量风格化适配层，明确责任边界）
3. **④⑤豁免加连锁影响声明**（MVP 期 ② 审核台降级为"段子+基础元信息"、进化暂停、RAG 监控待 cron 建成）。
4. **RAG 阈值标"待校准"** + 明确监控 cron 归属；**省→花拐点**类比 RAG 定义计算/存储/延迟量化线。
5. **"安全但无聊"失败模式**：Phase 3 落地质量>数量机制（传播力维度加权）。
